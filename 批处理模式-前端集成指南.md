# 批处理模式前端集成指南

## 📋 集成概述

本文档详细说明如何将批处理功能集成到OCRDetectionScreen中，包括实时检测时缓存ROI ID、判断目标齐全、触发批处理和显示结果。

---

## 🎯 集成目标

1. **实时检测时缓存ROI到后端**，返回并保存`roi_id`
2. **判断所有目标检测齐全**
3. **自动触发批处理API**
4. **显示批处理结果**（拼接图、OCR文本、条码数、合格状态）

---

## 🔧 集成步骤

### Step 1: 修改实时YOLO检测，缓存ROI到后端

在`performRealtimeDetection`函数中，当检测到目标时，不仅在前端保存ROI，还要发送到后端缓存并获取`roi_id`：

```typescript
// 位置：OCRDetectionScreen.tsx 中的 performRealtimeDetection 函数

const cacheROIToBackend = async (
  label: string, 
  roiImageDataUrl: string, 
  bbox: any,
  detection: any
): Promise<string | null> => {
  try {
    // 将ROI图像和元数据发送到后端
    const response = await fetch('/api/yolo/cache-roi/', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        label,
        roi_image: roiImageDataUrl,  // Base64
        bbox,
        detection
      })
    });
    
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }
    
    const data = await response.json();
    return data.roi_id;  // 返回后端生成的ROI ID
    
  } catch (error) {
    console.error('缓存ROI到后端失败:', error);
    return null;
  }
};

// 在检测到ROI后调用
for (const detection of validDetections) {
  const label = detection.label;
  
  // 提取ROI图像（现有逻辑）
  const roiImage = extractROI(frameDataUrl, detection.bbox);
  
  // 缓存到后端
  const roi_id = await cacheROIToBackend(
    label, 
    roiImage, 
    detection.bbox,
    detection
  );
  
  if (roi_id) {
    // 保存到store
    updateRoiCacheId(label, roi_id);
    console.log(`✅ ROI已缓存: ${label} -> ${roi_id}`);
  }
}
```

### Step 2: 判断目标齐全并触发批处理

```typescript
// 检查是否所有目标都检测到了
const checkAllTargetsDetected = useCallback(() => {
  // 如果不是批处理模式，跳过
  if (batchProcessingMode !== 'batch') {
    return false;
  }
  
  // 如果已经触发过批处理，跳过
  if (batchTriggered) {
    return false;
  }
  
  // 检查selectedTargets是否都在roiCacheIds中
  const cachedLabels = Object.keys(roiCacheIds);
  const allDetected = selectedTargets.every(target => 
    cachedLabels.includes(target)
  );
  
  return allDetected && cachedLabels.length > 0;
}, [
  batchProcessingMode, 
  batchTriggered, 
  selectedTargets, 
  roiCacheIds
]);

// 触发批处理
const triggerBatchProcessing = useCallback(async () => {
  if (!checkAllTargetsDetected()) {
    return;
  }
  
  console.log('🚀 所有目标检测齐全，触发批处理');
  setBatchTriggered(true);
  
  try {
    // 调用批处理API
    const result = await processBatch(roiCacheIds, {
      mode: 'batch',
      applyRules: batchApplyRules,
      enableBarcode: enableBarcodeDetection,
      targetConfigs: {
        // 将keywordConfigs转换为后端需要的格式
        ...selectedTargets.reduce((acc, target) => {
          const config = keywordConfigs.find(k => k.text === target);
          if (config) {
            acc[target] = {
              enable_keywords: enableKeywordAnalysis,
              required_keywords: config.text,
              require_barcode: false,
            };
          }
          return acc;
        }, {} as Record<string, any>)
      }
    });
    
    if (result) {
      // 显示结果
      displayBatchResult(result);
    }
    
  } catch (error) {
    console.error('批处理失败:', error);
    toast.error('批处理失败');
  }
}, [
  checkAllTargetsDetected,
  roiCacheIds,
  batchApplyRules,
  enableBarcodeDetection,
  processBatch
]);
```

### Step 3: 在实时检测中调用检查和触发

```typescript
// 在 performRealtimeDetection 的末尾添加
useEffect(() => {
  if (checkAllTargetsDetected()) {
    // 延迟100ms触发，确保状态已更新
    setTimeout(() => {
      triggerBatchProcessing();
    }, 100);
  }
}, [roiCacheIds, checkAllTargetsDetected, triggerBatchProcessing]);
```

### Step 4: 显示批处理结果

```typescript
const displayBatchResult = useCallback((result: BatchProcessingResult) => {
  console.log('📊 批处理结果:', result);
  
  // 更新OCR结果显示
  setOcrResult({
    success: true,
    fullText: result.ocr_text,
    detailedResults: result.details.map(d => ({
      text: d.ocr_text,
      confidence: 0,
      bbox: d.bbox
    })),
    matchStatus: result.overall_quality === '合格' ? 'qualified' : 'unqualified',
    overallQuality: result.overall_quality,
    reason: result.reason
  });
  
  // 更新拼接图预览
  if (result.stitched_image) {
    setImagePreview(result.stitched_image);
  }
  
  // 显示条码数量
  if (result.barcode_count > 0) {
    toast.success(`检测到 ${result.barcode_count} 个条码/二维码`);
  }
  
  // 显示处理时间
  console.log(
    `⏱️ 批处理性能: ${result.roi_count}个ROI, ` +
    `耗时${result.processing_time}s, ` +
    `模式=${result.processing_mode}, ` +
    `worker=${result.worker_count}`
  );
  
  // 更新工作流状态
  setWorkflowState('completed');
  setFinalResult(result.overall_quality === '合格' ? 'qualified' : 'unqualified');
  
  // 重置批处理状态（为下一次检测做准备）
  setTimeout(() => {
    resetBatchState();
  }, 2000);
  
}, [setOcrResult, setImagePreview, setWorkflowState, setFinalResult, resetBatchState]);
```

## 🔌 后端API补充

需要添加一个ROI缓存API端点（可选，也可以直接在实时检测时返回roi_id）：

```python
# backend/inspection/views.py 或 realtime_detection_api.py

@api_view(['POST'])
def cache_roi(request):
    """缓存单个ROI到后端"""
    try:
        label = request.data.get('label')
        roi_image_base64 = request.data.get('roi_image')
        bbox = request.data.get('bbox')
        detection = request.data.get('detection', {})
        
        # 解码Base64图像
        import base64
        import io
        import cv2
        import numpy as np
        from PIL import Image
        
        image_data = roi_image_base64.split(',')[1] if ',' in roi_image_base64 else roi_image_base64
        image_bytes = base64.b64decode(image_data)
        image = Image.open(io.BytesIO(image_bytes))
        roi_array = np.array(image)
        
        # 缓存ROI
        from inspection.roi_cache import get_roi_cache
        roi_cache = get_roi_cache()
        
        roi_id = roi_cache.store(
            label=label,
            roi_image=roi_array,
            bbox=bbox,
            detection=detection
        )
        
        return Response({
            'success': True,
            'roi_id': roi_id,
            'label': label
        })
        
    except Exception as e:
        logger.error(f"缓存ROI失败: {e}")
        return Response({
            'success': False,
            'error': str(e)
        }, status=500)

# 添加到urls.py
path('api/yolo/cache-roi/', cache_roi, name='cache_roi'),
```

**更推荐的方案**：直接在实时YOLO检测API中返回`roi_id`，无需额外请求：

```python

@api_view(['POST'])
def yolo_detect(request):
    # ... 现有检测逻辑 ...
    
    # 在返回检测结果时，同时缓存ROI
    from inspection.roi_cache import get_roi_cache
    roi_cache = get_roi_cache()
    
    for detection in detections:
        # 提取ROI
        roi_image = extract_roi_from_frame(frame, detection['bbox'])

            label=detection['label'],
            roi_image=roi_image,

        # 添加roi_id到检测结果
        detection['roi_id'] = roi_id
    
    return Response({
        'detections': detections,  # 每个detection现在包含roi_id
        # ... 其他字段
    })
```

## ⚠️ 注意事项

1. **并发安全**：实时检测和批处理之间可能存在竞态条件，注意使用`batchTriggered`标志防止重复触发
2. **缓存过期**：ROI缓存默认5分钟过期，注意检测不要间隔太久
3. **内存管理**：批处理结束后记得调用`resetBatchState()`清理
4. **错误处理**：网络失败、超时等情况需要优雅降级
5. **性能监控**：观察`processing_time`，确认是否有性能提升

## 📊 预期性能提升

| 场景 | 旧方案（前端队列） | 新方案（批处理+CPU) | 提升 |
|------|-------------------|-------------------|------|
| 3个ROI | ~900ms | ~300ms | **3倍** |
| 5个ROI | ~1500ms | ~550ms | **2.7倍** |
| 10个ROI | ~3000ms | ~700ms | **4.3倍** |

**说明**: 以上为理论预期，实际性能取决于网络延迟、CPU性能和图像大小。
