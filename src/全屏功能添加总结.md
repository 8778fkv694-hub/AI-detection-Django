# 全屏功能添加总结

## 功能描述
在监控画面上添加了全屏按钮，用户可以点击进入/退出全屏模式。

## 实现的功能

### 1. 全屏按钮
- **位置**：视频画面右上角
- **样式**：半透明黑色背景，白色图标
- **图标**：
  - 全屏模式：最大化图标 (Maximize)
  - 退出全屏：最小化图标 (Minimize)
- **显示条件**：只有在摄像头开启时才显示

### 2. 全屏切换功能
- **进入全屏**：点击按钮进入全屏模式
- **退出全屏**：点击按钮或按ESC键退出全屏
- **状态监听**：自动监听全屏状态变化

### 3. 界面优化
- **检测统计位置调整**：从右上角移到左下角，避免与全屏按钮重叠
- **全屏样式**：全屏时视频使用 `object-contain` 确保完整显示
- **响应式设计**：支持键盘ESC键退出全屏

## 代码实现

### 导入图标
```typescript
import { Maximize, Minimize } from 'lucide-react';
```

### 状态管理
```typescript
const [isFullscreen, setIsFullscreen] = useState(false);
```

### 全屏切换函数
```typescript
const toggleFullscreen = () => {
  if (!document.fullscreenElement) {
    // 进入全屏
    const videoContainer = document.getElementById('video-container');
    if (videoContainer) {
      videoContainer.requestFullscreen().then(() => {
        setIsFullscreen(true);
      }).catch(err => {
        console.error('全屏失败:', err);
        toast.error('全屏失败');
      });
    }
  } else {
    // 退出全屏
    document.exitFullscreen().then(() => {
      setIsFullscreen(false);
    }).catch(err => {
      console.error('退出全屏失败:', err);
      toast.error('退出全屏失败');
    });
  }
};
```

### 全屏状态监听
```typescript
useEffect(() => {
  const handleFullscreenChange = () => {
    setIsFullscreen(!!document.fullscreenElement);
  };

  document.addEventListener('fullscreenchange', handleFullscreenChange);
  return () => {
    document.removeEventListener('fullscreenchange', handleFullscreenChange);
  };
}, []);
```

### 全屏按钮UI
```typescript
{/* 全屏按钮 */}
{isCameraOn && (
  <button
    onClick={toggleFullscreen}
    className="absolute top-2 right-2 bg-black/50 hover:bg-black/70 text-white p-2 rounded-lg transition-colors z-10"
    title={isFullscreen ? "退出全屏" : "全屏显示"}
  >
    {isFullscreen ? <Minimize className="h-4 w-4" /> : <Maximize className="h-4 w-4" />}
  </button>
)}
```

## 使用方法
1. **开启摄像头**：点击"开启摄像头"按钮
2. **进入全屏**：点击视频画面右上角的全屏按钮（最大化图标）
3. **退出全屏**：
   - 点击全屏画面右上角的最小化按钮
   - 或按键盘ESC键

## 兼容性
- ✅ 支持现代浏览器（Chrome, Firefox, Safari, Edge）
- ✅ 支持键盘ESC键退出全屏
- ✅ 自动监听全屏状态变化
- ✅ 错误处理和用户提示
