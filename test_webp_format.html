🎨 WebP格式测试工具

用于测试和验证流媒体WebP格式是否正常工作

📋 快速测试步骤

步骤1: 打开浏览器开发者工具

按 F12 或 Cmd+Option+I (Mac) / Ctrl+Shift+I (Windows)

步骤2: 切换到Network标签

在开发者工具中点击 Network（网络） 标签

步骤3: 启动流媒体播放

在你的应用中启动一个虚拟流媒体摄像头

步骤4: 检查网络请求

  1. 在Network标签中，过滤输入 frame
  2. 找到 /api/streams/{id}/frame 请求
  3. 点击请求，查看URL参数
  4. 确认包含 format=webp

步骤5: 验证响应

  1. 点击请求，切换到 Response（响应） 标签
  2. 查看 frame 字段
  3. 应该以 data:image/webp;base64, 开头

🔍 控制台检查脚本

在浏览器控制台中运行以下代码来检查格式：

// 检查当前使用的格式
const checkFormat = () => {
  const requests = performance.getEntriesByType('resource')
    .filter(r => r.name.includes('/frame'))
    .map(r => {
      const url = new URL(r.name);
      return {
        url: r.name,
        format: url.searchParams.get('format') || '未指定',
        size: (r.transferSize / 1024).toFixed(2) + ' KB',
        duration: r.duration.toFixed(2) + ' ms'
      };
    });
  
  if (requests.length === 0) {
    console.log('❌ 未找到frame请求，请先启动流媒体播放');
    return null;
  }
  
  console.table(requests);
  
  const lastRequest = requests[requests.length - 1];
  if (lastRequest.format === 'webp') {
    console.log('✅ 正在使用WebP格式！');
  } else if (lastRequest.format === 'png') {
    console.log('⚠️ 正在使用PNG格式（建议切换到WebP）');
  } else if (lastRequest.format === 'jpeg') {
    console.log('⚠️ 正在使用JPEG格式（建议切换到WebP）');
  } else {
    console.log('❓ 格式未知:', lastRequest.format);
  }
  
  return requests;
};

// 运行检查
checkFormat();

🔄 切换格式的方法

方法1: 修改代码（推荐）

在创建 StreamPlayer 时指定格式：

const player = new StreamPlayer({
  videoElement: videoRef.current!,
  streamId: streamId,
  format: 'webp',  // 或 'png' 或 'jpeg'
  // ... 其他配置
});

方法2: 直接API调用

在代码中直接调用API时指定格式：

// WebP格式（推荐）
const frame = await getStreamFrame(streamId, 95, 1280, 'webp');

// PNG格式（对比用）
const frame = await getStreamFrame(streamId, 95, 1280, 'png');

// JPEG格式（对比用）
const frame = await getStreamFrame(streamId, 95, 1280, 'jpeg');
