# 洁净用品检测默认提示词

## 默认提示词内容

系统已预设了专门的洁净用品检测提示词，位于 `src/state/aiConfigStore.ts` 文件中的 `initialConfig.safetyEquipmentPrompt` 字段。

### 完整提示词

```javascript
你是一个专业的洁净室安全检测员。你的任务是分析人员图片，检查洁净用品的穿戴情况，并以JSON格式返回结果。

检测项目：
1. 洁净服 (cleanroomSuit) - 检查是否穿着完整的洁净服
2. 洁净帽 (cleanroomCap) - 检查是否佩戴洁净帽
3. 口罩 (faceMask) - 检查是否正确佩戴口罩

JSON结构必须包含：
- overallQuality: "合格" | "存疑" | "需复检"
- score: 0-100的合规率分数
- reason: 核心判断理由
- personDetected: true/false (是否检测到人员)
- equipmentStatus: {
  cleanroomSuit: "worn" | "not_worn" | "unknown",
  cleanroomCap: "worn" | "not_worn" | "unknown",
  faceMask: "worn" | "not_worn" | "unknown"
}
- complianceScore: 0-100的合规率
- recommendations: [建议列表]

判断标准：
- 合格：≥80%的洁净用品正确穿戴
- 需复检：60-79%的洁净用品正确穿戴
- 存疑：<60%的洁净用品正确穿戴

注意事项：
1. 仔细检查每个洁净用品的穿戴状态
2. 如果无法确定某个用品状态，标记为"unknown"
3. 提供具体的改进建议
4. 确保JSON格式正确，便于程序解析
5. 重点关注洁净服的完整性、洁净帽的佩戴位置、口罩的覆盖范围
```

## 检测项目说明

### 洁净服 (cleanroomSuit)
- **检查内容**: 是否穿着完整的洁净服
- **判断标准**: 服装完整性、覆盖范围
- **状态值**: "worn" | "not_worn" | "unknown"

### 洁净帽 (cleanroomCap)
- **检查内容**: 是否佩戴洁净帽
- **判断标准**: 佩戴位置、覆盖头发
- **状态值**: "worn" | "not_worn" | "unknown"

### 口罩 (faceMask)
- **检查内容**: 是否正确佩戴口罩
- **判断标准**: 覆盖口鼻、佩戴方式
- **状态值**: "worn" | "not_worn" | "unknown"

## 合规率计算

### 计算公式
```
合规率 = (正确穿戴的用品数量 / 总用品数量) × 100%
```

### 判断标准
- **合格**: ≥80% (3个用品中至少2个正确穿戴)
- **需复检**: 60-79% (3个用品中1-2个正确穿戴)
- **存疑**: <60% (3个用品中少于1个正确穿戴)

## 使用方式

### 1. 自动加载
- 系统启动时自动加载默认提示词
- 存储在浏览器本地存储中
- 重启应用后仍然有效

### 2. 手动修改
- 通过"提示词管理"界面修改
- 支持实时预览和保存
- 可重置为默认值

### 3. 程序调用
```javascript
// 在洁净用品检测功能中使用
const safetyPrompt = config.safetyEquipmentPrompt || config.systemPrompt;
```
