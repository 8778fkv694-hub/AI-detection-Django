# PPE检测系统

## 概述

这是一个专门用于检测个人防护装备（PPE）的系统，支持实时检测和自动抓拍功能。

## 功能特性

### 🔍 检测能力
- **人员检测** (`person`) - 检测人员存在
- **帽子检测** (`hat`) - 检测各种头饰
- **口罩检测** (`mask`) - 检测面部防护装备
- **洁净服检测** (`cleanroom_suit`) - 检测工作服/洁净服
- **手套检测** (`gloves`) - 检测手部防护装备
- **护目镜检测** (`safety_glasses`) - 检测眼部防护装备
- **PPE装备检测** (`ppe_equipment`) - 检测其他防护装备

### 🎨 可视化
- 不同PPE类别使用不同颜色标识
- 实时显示检测置信度
- 检测统计信息（人员数量、装备数量）

### ⚙️ 配置选项
- 抓拍阈值设置（0.1-0.95）
- 检测阈值设置（0.1-0.95）
- 自动抓拍间隔（1-60秒）
- 自动抓拍开关

## 技术架构

### 后端 (Django)
- **模型**: 支持自定义PPE检测模型
- **API**: `/api/results/yolo-detect/` 提供检测服务
- **类别映射**: 自动将检测结果映射到PPE类别

### 前端 (React + TypeScript)
- **实时检测**: 每秒执行一次检测
- **自动抓拍**: 检测到人员时自动抓拍
- **结果分析**: 自动分析PPE穿戴合规性

## 使用方法

1. **启动后端服务**
   ```bash
   cd backend
   python3 manage.py runserver 8000
   ```

2. **启动前端服务**
   ```bash
   npm run dev
   ```

3. **使用系统**
   - 开启摄像头
   - 点击"开始监控"
   - 系统自动检测PPE穿戴情况

## 模型配置

系统优先使用专门的PPE检测模型。如需使用自定义模型：

1. 将模型文件放在 `backend/ppe_detection.pt`
2. 或设置环境变量 `PPE_MODEL_PATH`

## 检测结果

系统会返回以下信息：
- 检测到的PPE类别
- 置信度分数
- 边界框坐标
- 合规性分析
- 改进建议
