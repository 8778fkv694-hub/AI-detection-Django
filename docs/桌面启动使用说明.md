# AI检测项目 - 桌面启动使用说明

## 🚀 一键启动方法

### 方法一：双击.command文件（推荐）
1. 在桌面上找到 `启动AI检测项目.command` 文件
2. 双击该文件
3. 系统会自动打开终端并启动项目

### 方法二：双击AppleScript文件
1. 在桌面上找到 `AI检测项目启动器.applescript` 文件
2. 双击该文件
3. 系统会自动启动项目

### 方法三：直接运行脚本
1. 打开终端
2. 进入项目目录
3. 运行 `./简单启动.sh` 或 `./快速启动.sh`

## 📁 文件说明

### 核心文件
- `AI检测项目.desktop` - Linux/macOS 桌面文件
- `AI检测项目.app` - macOS 应用程序包
- `桌面启动.sh` - 简化的启动脚本
- `启动AI检测项目.sh` - 完整的交互式启动脚本
- `start_full_project.sh` - 核心启动脚本

### 启动流程
1. 检查环境依赖（Python3, Node.js, npm）
2. 启动Django后端服务器
3. 启动React前端服务器
4. 显示访问地址和状态信息

## 🌐 访问地址

启动成功后，您可以通过以下地址访问：

- **前端界面**: http://localhost:3303
- **Node.js后端**: http://localhost:3001
- **Django后端API**: http://localhost:8000/api/
- **管理后台**: http://localhost:8000/admin
- **数据同步状态**: http://localhost:8000/api/sync/status/

## 🛑 停止服务

要停止所有服务，请运行：
```bash
./stop_services.sh
```

## 🔧 故障排除

### 如果双击无法启动
1. 检查文件权限：
   ```bash
   chmod +x AI检测项目.desktop
   chmod +x 桌面启动.sh
   chmod +x start_full_project.sh
   ```

2. 检查依赖是否安装：
   - Python3
   - Node.js
   - npm

3. 查看日志文件：
   - Django后端日志：`django.log`
   - React前端日志：`react.log`

### 如果端口被占用
- 检查端口 8000 和 3303 是否被其他程序占用
- 使用 `lsof -i :8000` 和 `lsof -i :3303` 查看端口使用情况

## 📝 注意事项

1. **首次启动**：可能需要较长时间来安装依赖
2. **HTTPS证书**：首次访问前端时可能需要接受HTTPS证书
3. **防火墙**：确保防火墙允许访问相关端口
4. **权限问题**：确保脚本有执行权限
