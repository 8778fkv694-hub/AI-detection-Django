# 洁净用品检测功能说明

## 功能概述

新增的洁净用品检测功能通过YOLO模型进行实时监控，检测人员出现后跟踪目标并保存截图，截图上传到视觉大模型检查洁净用品的穿戴情况（是否按标准穿戴）并返回结果。

## 检测项目

系统检测以下三种洁净用品：

1. **洁净服** - 检查人员是否穿着洁净服
2. **洁净帽** - 检查人员是否佩戴洁净帽  
3. **口罩** - 检查人员是否佩戴口罩

## 功能特点

### 实时监控
- 使用YOLO模型进行人员检测
- 支持自动抓拍和手动抓拍
- 可调节检测阈值和抓拍间隔
- 实时显示检测到的人员数量

### 智能检测
- 使用视觉大模型分析抓拍图片
- 自动识别洁净用品穿戴状态
- 计算合规率并给出评估结果
- 提供具体的改进建议

### 结果管理
- 检测结果自动保存到数据库
- 支持查看历史检测记录
- 详细显示每项洁净用品状态
- 提供合规率统计

## 使用方法

### 基本操作
1. 点击"洁净用品检测"选项卡
2. 开启摄像头
3. 点击"开始监控"启动YOLO检测
4. 系统自动检测人员并抓拍
5. 点击"开始洁净用品检测"分析图片
6. 查看检测结果和建议

### 快捷键
- **空格键** - 手动抓拍
- **回车键** - 开始检测
- **M键** - 开始/停止监控

### 设置选项
- **自动抓拍** - 检测到人员时自动抓拍
- **抓拍间隔** - 设置自动抓拍的时间间隔（3秒/5秒/10秒）
- **检测阈值** - 调整YOLO检测的置信度阈值

## 检测结果说明

### 合规等级
- **合格** (≥80%) - 所有洁净用品都正确穿戴
- **需复检** (60-79%) - 部分洁净用品未正确穿戴
- **存疑** (<60%) - 大部分洁净用品未正确穿戴

### 状态指示
- ✅ **已穿戴** - 绿色显示，表示该用品已正确穿戴
- ❌ **未穿戴** - 红色显示，表示该用品未穿戴或穿戴不当

## 技术实现

### 核心功能
- 摄像头实时视频流处理
- Canvas图像处理和标注

## 注意事项

1. **摄像头权限** - 首次使用需要授权摄像头访问权限
2. **网络连接** - 视觉大模型分析需要网络连接（当前为模拟）
3. **光线条件** - 良好的光线条件有助于提高检测准确率
4. **人员位置** - 人员应在摄像头视野范围内且清晰可见
