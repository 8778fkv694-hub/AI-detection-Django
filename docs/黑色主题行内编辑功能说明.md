# 黑色主题行内编辑功能说明

## 功能概述

为洁净用品结果页面的发送报告功能添加了黑色主题UI和行内编辑功能，提供更好的用户体验和更直观的编辑方式。

## 主要改进

### 1. 黑色主题UI
- **对话框背景**: 使用深色slate-900背景
- **卡片样式**: 深色slate-800背景，slate-700边框
- **文字颜色**: 白色主文字，slate-300次要文字
- **输入框**: 深色slate-700背景，slate-600边框
- **按钮**: 适配深色主题的按钮样式

### 2. 行内编辑功能
- **点击编辑**: 点击任何字段即可进入编辑模式
- **实时保存**: 支持Enter键保存，Escape键取消
- **视觉反馈**: 编辑状态有明显的视觉区分
- **操作按钮**: 提供确认(✓)和取消(✕)按钮

## 功能特点

### 编辑模式切换
- **显示模式**: 显示当前值，点击进入编辑
- **编辑模式**: 显示输入框和操作按钮
- **占位符**: 未设置值时显示友好的提示文字

### 键盘快捷键
- **Enter**: 保存编辑内容
- **Escape**: 取消编辑，恢复原值
- **Shift+Enter**: 在文本域中换行

### 字段类型支持
- **日期时间**: datetime-local输入框
- **文本输入**: 单行文本输入框
- **多行文本**: textarea文本域
- **必填验证**: 检查地点为必填项

## 使用方法

### 1. 打开报告对话框
1. 进入"洁净用品结果"页面
2. 点击右上角的"发送报告"按钮

### 2. 编辑报告信息
1. **设置时间范围**:
   - 点击"检查开始时间"字段
   - 选择日期和时间
   - 按Enter或点击✓保存

2. **设置检查地点**:
   - 点击"检查地点"字段（必填）
   - 输入地点信息
   - 按Enter或点击✓保存

3. **设置报告描述**:
   - 点击"报告描述"字段
   - 输入描述信息（支持多行）
   - 按Enter或点击✓保存

### 3. 发送报告
1. 确认所有信息填写完整
2. 点击"发送报告"按钮
3. 等待发送完成

## 技术实现

### 状态管理
```typescript
// 行内编辑状态
const [editingField, setEditingField] = useState<string | null>(null);
const [editValue, setEditValue] = useState('');
```

### 编辑处理函数
```typescript
// 开始编辑
const startEdit = (field: string, currentValue: string) => {
  setEditingField(field);
  setEditValue(currentValue);
};

// 保存编辑
const saveEdit = () => {
  if (editingField) {
    setReportData(prev => ({
      ...prev,
      [editingField]: editValue
    }));
    setEditingField(null);
    setEditValue('');
  }
};

// 取消编辑
const cancelEdit = () => {
  setEditingField(null);
  setEditValue('');
};
```

### 键盘事件处理
```typescript
const handleKeyDown = (e: React.KeyboardEvent) => {
  if (e.key === 'Enter' && !e.shiftKey) {
    e.preventDefault();
    saveEdit();
  } else if (e.key === 'Escape') {
    e.preventDefault();
    cancelEdit();
  }
};
```

## UI组件结构

### 编辑字段组件
```tsx
{editingField === 'fieldName' ? (
  // 编辑模式
  <div className="flex gap-2">
    <input
      value={editValue}
      onChange={(e) => setEditValue(e.target.value)}
      onKeyDown={handleKeyDown}
      className="flex-1 px-3 py-2 bg-slate-700 border border-slate-600 rounded-md text-white focus:outline-none focus:ring-2 focus:ring-blue-500"
      autoFocus
    />
    <Button onClick={saveEdit}>✓</Button>
    <Button onClick={cancelEdit}>✕</Button>
  </div>
) : (
  // 显示模式
  <div
    onClick={() => startEdit('fieldName', reportData.fieldName)}
    className="px-3 py-2 bg-slate-700 border border-slate-600 rounded-md text-white cursor-pointer hover:bg-slate-600 transition-colors"
  >
    {reportData.fieldName || '点击设置字段值'}
  </div>
)}
```

## 样式特点

### 颜色方案
- **主背景**: `bg-slate-900` (深灰黑)
- **卡片背景**: `bg-slate-800` (深灰)
- **输入框背景**: `bg-slate-700` (中灰)
- **边框颜色**: `border-slate-700/600` (灰色边框)
- **文字颜色**: `text-white/slate-300` (白色/浅灰)

- **过渡动画**: `transition-colors` (平滑颜色过渡)
