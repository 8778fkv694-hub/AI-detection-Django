# 洁净用品检测提示词管理说明

## 功能概述

洁净用品检测功能使用专门的AI提示词来分析人员图片，检查洁净用品的穿戴情况。用户可以通过提示词管理界面查看、修改和保存这些提示词。

## 提示词位置

### 1. 提示词管理界面
- **路径**: 点击左侧导航栏的"提示词管理"选项卡
- **功能**: 查看和修改洁净用品检测的提示词
- **访问**: 应用启动后，在左侧菜单中点击"提示词管理"

### 2. 配置文件位置
- **前端配置**: `src/state/aiConfigStore.ts`
- **类型定义**: `src/types/index.ts`
- **默认提示词**: 在AI配置存储中定义

## 提示词内容

### 洁净用品检测提示词
```javascript
你是一个专业的洁净室安全检测员。你的任务是分析人员图片，检查洁净用品的穿戴情况，并以JSON格式返回结果。

检测项目：
1. 洁净服 (cleanroomSuit) - 检查是否穿着完整的洁净服
2. 洁净帽 (cleanroomCap) - 检查是否佩戴洁净帽
3. 口罩 (faceMask) - 检查是否正确佩戴口罩

JSON结构必须包含：
- overallQuality: "合格" | "存疑" | "需复检"
- score: 0-100的合规率分数
- reason: 核心判断理由
- personDetected: true/false (是否检测到人员)
- equipmentStatus: {
  cleanroomSuit: "worn" | "not_worn" | "unknown",
  cleanroomCap: "worn" | "not_worn" | "unknown",
  faceMask: "worn" | "not_worn" | "unknown"
}
- complianceScore: 0-100的合规率
- recommendations: [建议列表]

判断标准：
- 合格：≥80%的洁净用品正确穿戴
- 需复检：60-79%的洁净用品正确穿戴
- 存疑：<60%的洁净用品正确穿戴
```

## 修改提示词的方法

### 方法1: 通过提示词管理界面
1. 打开应用，点击左侧"提示词管理"
2. 选择"洁净用品检测"选项卡
3. 在文本框中修改提示词内容
4. 点击"保存更改"按钮

### 方法2: 直接修改代码
1. 打开 `src/state/aiConfigStore.ts` 文件
2. 找到 `initialConfig` 对象
3. 修改 `safetyEquipmentPrompt` 字段
4. 重新启动应用

### 方法3: 通过浏览器开发者工具
1. 打开浏览器开发者工具 (F12)
2. 进入 Application/Storage 标签
3. 找到 Local Storage 中的 `wyl-ai-config-storage`
4. 修改 `safetyEquipmentPrompt` 值

## 提示词使用流程

1. **检测触发**: 用户在洁净用品检测界面点击"开始洁净用品检测"
2. **提示词获取**: 系统从配置中获取 `safetyEquipmentPrompt`
3. **AI调用**: 将提示词和图片发送给AI模型
4. **结果解析**: 解析AI返回的JSON格式结果
5. **结果展示**: 在界面上显示检测结果和建议

## 提示词优化建议

### 提高检测准确性
- 明确指定检测项目和标准
- 包含具体的判断条件
- 要求AI提供详细的理由说明

### 改进JSON格式
- 确保JSON结构清晰明确
- 包含所有必要的字段
- 使用统一的命名规范

### 增强用户体验
- 提供具体的改进建议
- 包含合规率计算说明
- 支持多种检测状态

## 注意事项

1. **格式要求**: 提示词必须包含完整的JSON结构说明
2. **字段一致性**: 确保提示词中的字段名与代码中的类型定义一致
3. **保存操作**: 修改后必须点击保存才能生效
4. **备份建议**: 修改前建议备份当前配置
5. **测试验证**: 修改后建议进行测试验证

## 故障排除

### 提示词不生效
- 检查是否已保存更改
- 确认配置已正确加载
- 查看浏览器控制台是否有错误

### 检测结果异常
- 检查JSON格式是否正确
- 确认字段名是否匹配
- 验证提示词逻辑是否合理

### 界面显示问题
- 刷新页面重新加载配置
- 检查浏览器缓存
- 确认组件正确导入
