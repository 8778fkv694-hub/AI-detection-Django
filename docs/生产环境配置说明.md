# AI检测系统生产环境配置说明

## 🚀 端口配置

### 推荐端口配置
- **前端HTTPS**: `443` (标准HTTPS端口)
- **前端HTTP**: `80` (标准HTTP端口，自动重定向到HTTPS)
- **后端API**: `8012` (直接访问后端API)
- **数据库**: `5432` (PostgreSQL)
- **Redis**: `6379` (Redis缓存)

### 访问地址
- **前端界面 (HTTPS)**: `https://your-domain.com` 或 `https://your-ip:443`
- **前端界面 (HTTP)**: `http://your-domain.com` 或 `http://your-ip:80` (自动重定向到HTTPS)
- **后端API**: `http://your-domain.com:8012/api/` 或 `http://your-ip:8012/api/`
- **管理后台**: `http://your-domain.com:8012/admin/` 或 `http://your-ip:8012/admin/`

## 🐳 Docker配置

### 服务架构
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Nginx (80/443)│────│  Django App     │────│  PostgreSQL     │
│   (反向代理)     │    │  (8012)         │    │  (5432)         │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                                │
                       ┌─────────────────┐
                       │     Redis       │
                       │     (6379)      │
                       └─────────────────┘
```

### 容器配置
- **nginx**: 处理HTTP/HTTPS请求，反向代理到Django应用
- **app**: Django应用，提供API和管理后台
- **db**: PostgreSQL数据库
- **redis**: Redis缓存

## 📁 文件结构

```
production/
├── .env                    # 环境变量配置
├── nginx.conf             # Nginx配置

│   └── server.key

start_mac.sh production    # Mac 本地生产预览入口

test_production.sh         # 生产环境测试脚本
```

## 🔧 部署步骤

### 1. 快速部署
```bash
# 一键部署生产环境
./deploy_production.sh
```

### 2. 手动部署
```bash
# 1. 配置环境变量
cp production/env.example production/.env
# 编辑 production/.env 文件

# 2. 构建前端
npm install
npm run build

# 3. 启动生产环境
docker-compose -f docker-compose.prod.yml up -d --build

# 4. 运行数据库迁移
docker-compose -f docker-compose.prod.yml exec app python manage.py migrate

# 5. 创建超级用户
docker-compose -f docker-compose.prod.yml exec app python manage.py createsuperuser
```

### 3. 测试部署
```bash
# 测试生产环境配置
./test_production.sh
```

## 📊 监控和维护

### 查看日志
```bash
# 查看所有服务日志
docker-compose -f docker-compose.prod.yml logs -f

# 查看特定服务日志
docker-compose -f docker-compose.prod.yml logs -f nginx
docker-compose -f docker-compose.prod.yml logs -f app
```

### 服务管理
```bash
# 停止服务
docker-compose -f docker-compose.prod.yml down

# 重启服务
docker-compose -f docker-compose.prod.yml restart

# 更新服务
docker-compose -f docker-compose.prod.yml up -d --build
```

### 数据备份
```bash
# 备份数据库
docker-compose -f docker-compose.prod.yml exec db pg_dump -U qainspect qainspect > backup.sql

# 备份媒体文件
docker-compose -f docker-compose.prod.yml exec app tar -czf /tmp/media_backup.tar.gz /app/backend/media
```

## 🚨 故障排除

### 常见问题

1. **端口被占用**
   ```bash
   # 检查端口占用
   lsof -i :80
   lsof -i :443
   lsof -i :8012
   ```

2. **SSL证书问题**
   - 检查证书文件是否存在
   - 确保证书格式正确
   - 检查证书权限

3. **数据库连接失败**
   - 检查数据库容器状态
   - 验证连接配置
   - 查看数据库日志

4. **前端无法访问**
   - 检查Nginx配置
   - 验证静态文件路径
   - 查看Nginx日志

### 日志位置
- **Nginx日志**: Docker容器内 `/var/log/nginx/`
- **应用日志**: Docker容器内 `/app/logs/`
- **数据库日志**: Docker容器内PostgreSQL日志
