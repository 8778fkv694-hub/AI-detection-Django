# 视觉模型配置模板

## 推荐的视觉模型

### 1. Qwen2.5-VL 系列
- **qwen2.5-vl-7b-instruct**: 7B参数，支持图文理解
- **qwen2.5-vl-14b-instruct**: 14B参数，更强的视觉能力
- **qwen2.5-vl-32b-instruct**: 32B参数，最佳性能

### 2. LLaVA 系列
- **llava-v1.6-mistral-7b**: 基于Mistral的视觉模型
- **llava-v1.6-vicuna-13b**: 基于Vicuna的视觉模型

### 3. 其他选择
- **bakllava**: 开源视觉语言模型
- **minicpm-v**: 轻量级视觉模型

## 安装新视觉模型

```bash
# 安装Qwen2.5-VL-7B
ollama pull qwen2.5-vl-7b-instruct

# 安装LLaVA
ollama pull llava-v1.6-mistral-7b

# 查看已安装模型
ollama list
```

## 性能优化建议

### 内存优化
- 使用较小的模型（7B参数）
- 启用CPU模式：`OLLAMA_NUM_GPU_LAYERS=0`
- 限制上下文长度：`num_ctx: 4096`

### 图片处理优化
- 压缩图片到512x512像素
- 使用JPEG格式，质量0.7
- 减少base64数据量

### 超时设置
- 视觉模型响应较慢，建议设置3-5分钟超时
- 当前配置：180秒（3分钟）

## 注意事项

1. **模型大小**: 视觉模型通常较大（7-32GB），确保有足够存储空间
2. **内存需求**: 建议至少16GB RAM用于7B模型
3. **响应时间**: 视觉模型比纯文本模型慢，需要耐心等待
4. **图片格式**: 支持JPEG、PNG等常见格式
5. **并发限制**: 建议单线程处理，避免内存不足
