# 洁净检测口罩帽子专用配置说明

## 概述
根据用户需求，系统已调整为只检测口罩和帽子的专用配置，移除了洁净服等其他PPE的检测功能。

## 修改内容

### 1. 后端PPE类别映射更新
**文件**: `backend/inspection/yolo.py`

**修改前**:
- 检测类别：洁净帽、口罩、蓝色洁净服
- 支持多种工作服映射

**修改后**:
- 检测类别：洁净帽、口罩
- 移除了洁净服相关的映射
- 专注于口罩和帽子的检测

**具体变更**:
```python
# 移除的映射
'safety vest': 'cleanroom_suit',
'suit': 'cleanroom_suit',
'uniform': 'cleanroom_suit',
'jacket': 'cleanroom_suit',
'coat': 'cleanroom_suit',
'workwear': 'cleanroom_suit',
'shirt': 'cleanroom_suit',
'clothing': 'cleanroom_suit',
'no-safety vest': 'no_cleanroom_suit',
```

### 2. 前端检测类别过滤更新
**文件**: `src/screens/SafetyEquipmentScreen.tsx`

**修改前**:
```typescript
const relevantClasses = ['person', 'cleanroom_cap', 'mask', 'cleanroom_suit', 'no_cleanroom_cap', 'no_mask', 'no_cleanroom_suit'];
```

**修改后**:
```typescript
const relevantClasses = ['person', 'cleanroom_cap', 'mask', 'no_cleanroom_cap', 'no_mask'];
```

### 3. PPE阈值配置更新
**修改前**:
```typescript

  cleanroom_cap: 0.8,    // 洁净帽检测阈值
```

```typescript
const [ppeThresholds, setPpeThresholds] = useState({
  cleanroom_cap: 0.8,    // 洁净帽检测阈值

});
```

### 4. 检测统计更新
**修改前**: 统计洁净帽、口罩、洁净服、人员
**修改后**: 只统计洁净帽、口罩、人员

### 5. 类型定义更新
**文件**: `src/types/index.ts`

**移除的字段**:
- `ppeDetections.cleanroom_suit`
- `ppeCompliance.hasCleanroomSuit`

### 6. 模型管理界面更新
**文件**: `src/screens/ModelManagementScreen.tsx`

**修改前**: 支持洁净服检测类别
**修改后**: 只支持口罩和帽子检测类别

## 当前检测配置

### ✅ 启用的检测类别
1. **人员检测** (`person`) - 检测人员存在
2. **洁净帽检测** (`cleanroom_cap`) - 检测洁净帽/安全帽
3. **口罩检测** (`mask`) - 检测口罩/面罩
4. **未戴洁净帽检测** (`no_cleanroom_cap`) - 检测未戴洁净帽
5. **未戴口罩检测** (`no_mask`) - 检测未戴口罩

### ❌ 已禁用的检测类别
1. **洁净服检测** (`cleanroom_suit`) - 已移除
2. **未穿洁净服检测** (`no_cleanroom_suit`) - 已移除

## 检测逻辑

### 合规性判断
- **洁净帽合规**: 检测到洁净帽 OR (有人员且未检测到"未戴洁净帽")
- **口罩合规**: 检测到口罩 OR (有人员且未检测到"未戴口罩")

### 合规率计算
```typescript
// 修改前：3项核心PPE
const complianceScore = Object.values(equipmentStatus).filter(e => e === 'worn').length / 3 * 100;

// 修改后：2项核心PPE（口罩和帽子）
const complianceScore = Object.values(equipmentStatus).filter(e => e === 'worn').length / 2 * 100;
```
