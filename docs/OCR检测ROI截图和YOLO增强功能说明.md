# OCR检测ROI截图和YOLO增强功能说明

## 🚀 新增功能概述

为OCR检测页面添加了ROI截图功能和增强的YOLO检测逻辑，支持多元素选择和OR/AND关系判断。

## ✨ 主要功能

### 1. ROI截图功能
- **全画面模式**：保存完整的检测图片
- **ROI截图模式**：根据YOLO检测结果自动裁剪检测框区域
- **自动拼接**：当检测到多个元素时，自动计算所有检测框的边界并裁剪

### 2. YOLO检测逻辑增强
- **OR模式**：识别到任一元素即抓拍
- **AND模式**：必须检测到所有选中的元素才抓拍
- **超时机制**：AND模式下可设置超时时间（3-15秒）
- **状态显示**：实时显示当前检测状态和等待的元素

### 3. 智能检测管理
- **检测状态跟踪**：记录已检测到的元素和开始时间
- **超时处理**：超时后自动重置检测状态并提示缺少的元素
- **状态重置**：工作流完成后自动重置所有检测状态

## 🎯 使用方法

### 设置ROI截图模式
1. 进入OCR检测页面
2. 展开"检测设置"面板
3. 在"自动检测保存模式"中选择：
   - **全画面**：保存完整图片
   - **ROI截图**：只保存检测框区域

### 配置YOLO检测逻辑
1. 在"YOLO检测逻辑"中选择：
   - **OR模式**：检测到任一元素即抓拍
   - **AND模式**：必须检测到所有元素才抓拍

2. 如果选择AND模式，可设置超时时间：
   - 3秒、5秒、10秒、15秒可选

### 选择检测目标
1. 在"检测目标"中选择要检测的元素：
   - 人员、口罩、安全帽等
2. 支持多选，根据OR/AND模式进行判断

## 📊 状态显示

### AND模式状态显示
当选择AND模式时，界面会显示：
- **已检测到**：当前已检测到的元素列表
- **等待元素**：还需要检测的元素列表
- **检测开始时间**：开始检测的时间戳

### 超时提示
当AND模式超时时，控制台会输出：
```
AND模式：检测超时 (5.2s > 5s)，缺少元素: 口罩, 安全帽
```

## 🔄 工作流程

1. **检测启动**：选择检测目标和逻辑模式
2. **实时检测**：YOLO模型持续检测视频流
3. **逻辑判断**：根据OR/AND模式判断是否抓拍
4. **图片处理**：根据保存模式处理图片（全画面/ROI）
5. **OCR分析**：对处理后的图片进行OCR识别
6. **结果保存**：保存检测结果和历史记录
7. **状态重置**：完成后重置所有检测状态

## 💡 使用建议

### OR模式适用场景
- 快速检测场景
- 只需要检测到任一元素即可
- 对检测速度要求高

### AND模式适用场景
- 需要完整检测的场景
- 必须同时检测到多个元素
- 对检测完整性要求高

### ROI截图适用场景
- 需要聚焦检测区域
- 减少存储空间
- 提高后续处理效率

## 🚨 注意事项

1. **AND模式超时**：如果超时时间内未检测到所有元素，会重置检测状态
2. **ROI截图质量**：ROI截图会添加20像素边距，确保检测框完整
3. **状态重置**：工作流完成后会自动重置所有检测状态
4. **性能优化**：检测循环每2秒执行一次，避免过度消耗资源

## 🔧 配置参数

- **检测置信度**：10%-95%可选
- **检测间隔**：1-5秒可选
- **AND模式超时**：3-15秒可选
- **ROI边距**：20像素（固定）
- **图片压缩质量**：80%（固定）

这些功能大大增强了OCR检测的灵活性和实用性，支持更复杂的检测场景和需求。
