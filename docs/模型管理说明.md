# Django模型管理说明

## 问题解答：为什么只看到3个模型版本？

### 模型结构说明

Django后端中有两种不同的模型概念：

#### 1. **ModelVersion（模型版本）** - 您看到的3个模型
这是存储在数据库中的**模型版本记录**，包括：
- YOLOv8n轻量模型
- YOLO10X通用模型  
- PPE检测模型

这些是已经上传并注册到系统的模型文件版本。

#### 2. **ModelConfig（模型配置）** - 包含"滤芯"和"净水机"
这是**模型类型配置**，定义了系统支持的不同模型类型：
- **PPE_YOLO** - PPE YOLO检测模型
- **YOLO_GENERAL** - 通用YOLO模型
- **FILTER_CORE** - 滤芯检测模型 ⭐
- **CUSTOM** - 自定义模型

"滤芯"和"净水机"实际上是作为**模型配置**存在的，而不是独立的模型版本。

### 模型配置详情

在代码中，`backend/inspection/model_config.py` 定义了以下模型配置：

1. **滤芯检测模型** (`filter_core_detection`)
   - 模型文件：`best.pt`
   - 检测类别：filter（过滤器）、filtername（过滤器名称）、nsplogo（NSP标志）、qrcode（二维码）
   - 模型类型：FILTER_CORE

2. **净水机检测模型** (`waterprifer_detection`)
   - 模型文件：`waterprifer.pt`
   - 检测类别：防伪标签、售后服务标签、铭牌标签、水效标签、条码标签
   - 模型类型：通过代码配置，但未单独存储在ModelVersion中

### 如何查看和管理模型配置

现在我已经将 `ModelConfig` 注册到Django Admin中，您可以：

1. **刷新Django管理界面**
2. **在左侧导航栏中找到 "Model configs"**
3. **点击进入查看所有模型配置**

您将看到：
- PPE YOLO检测模型
- 通用YOLO模型
- **滤芯检测模型** ⭐
- 自定义模型

### 如何将"滤芯"和"净水机"添加为模型版本

如果您希望将"滤芯"和"净水机"作为独立的模型版本显示在"Model versions"页面，需要：

1. **通过Django Admin创建新的ModelVersion记录**
   - 进入 "Model versions" 页面
   - 点击 "增加 model version"
   - 填写信息：
     - 名称：滤芯专用检测模型
     - 版本：1.0.0
     - 模型类型：选择 "PPE YOLO检测模型" 或创建新的类型
     - 状态：激活
     - 上传模型文件：best.pt

2. **或者通过Django Shell创建**

```python
from inspection.models import ModelVersion
from django.core.files import File

# 创建滤芯模型版本
filter_model = ModelVersion.objects.create(
    name='滤芯专用检测模型',
    version='1.0.0',
    model_type='PPE_YOLO',
    status='ACTIVE',
    description='专门用于滤芯检测的自定义训练模型，支持4个特定类别检测',
    # 需要上传模型文件
)

# 创建净水机模型版本
water_purifier_model = ModelVersion.objects.create(
    name='净水机专用检测模型',
    version='1.0.0',
    model_type='PPE_YOLO',
    status='ACTIVE',
    description='净水机标签识别模型，支持5类专用标签检测',
    # 需要上传模型文件
)
```
