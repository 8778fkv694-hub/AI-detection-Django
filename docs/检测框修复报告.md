# 检测框线显示问题修复报告

## 问题描述
用户反馈所有实时检测页面的框线标注功能都失效了，检测框无法正常显示。

## 问题分析
通过自动化测试和代码检查，发现了以下问题：

### 1. OpenCV导入问题
- **问题**: 在 `backend/inspection/views.py` 和 `backend/inspection/filter_core_detection_config.py` 中，`cv2` 被注释掉了
- **影响**: 导致YOLO检测API返回500错误，提示 `name 'cv2' is not defined`
- **修复**: 恢复了 `import cv2` 语句

### 2. 检测框绘制逻辑问题
- **问题**: 在 `drawDetections` 函数中，清除画布后没有重新绘制视频帧作为背景
- **影响**: 检测框绘制在空白画布上，用户看不到检测框
- **位置**: 
  - `src/screens/OCRTestScreen.tsx`
  - `src/screens/SafetyEquipmentScreen.tsx`

## 修复方案

### 1. 恢复OpenCV导入
```python
# backend/inspection/views.py
import cv2  # 恢复导入

# backend/inspection/filter_core_detection_config.py  
import cv2  # 恢复导入
```

### 2. 修复检测框绘制逻辑
