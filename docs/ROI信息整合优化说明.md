# ROI信息整合优化说明

## 优化概述

根据用户反馈，我们对ROI信息整合功能进行了重要优化，确保**无论选择哪种检测模式，系统都会自动整合ROI区域信息到检测提示词中**。

## 优化内容

### 1. 统一ROI信息整合
- ✅ **模式1（仅ROI信息）**：整合完整的ROI区域信息
- ✅ **模式2（发送标准图片）**：整合ROI信息 + 图片对比指导
- ✅ **智能位置描述**：自动生成"左侧上方的小区域"等描述
- ✅ **检测指导优化**：根据模式提供不同的检测说明

### 2. 提示词增强对比

#### 模式1：仅使用ROI区域信息
```
请严格按照以下标准检测：
- 标准名称: [模板名称]
- 附加标准: [检测要求]
- 重点关注区域:
  1. [区域名称]: [区域描述]
  2. [区域名称]: [区域描述]
  ...

请特别关注上述标注的区域，这些是检测的重点。

区域位置参考：
  1. [区域名称]: 位于[位置描述]
  2. [区域名称]: 位于[位置描述]
  ...

检测说明：请根据上述ROI区域的位置和描述信息，仔细检查检测图片中对应区域，判断是否符合标准要求。
```

#### 模式2：发送标准图片对比
```
请严格按照以下标准检测：
- 标准名称: [模板名称]
- 附加标准: [检测要求]
- 重点关注区域:
  1. [区域名称]: [区域描述]
  2. [区域名称]: [区域描述]
  ...

请特别关注上述标注的区域，这些是检测的重点。

区域位置参考：
  1. [区域名称]: 位于[位置描述]
  2. [区域名称]: 位于[位置描述]
  ...

检测说明：我将提供标准图片和检测图片，请对比两张图片，重点关注上述ROI区域，检查是否存在缺陷或不符合标准的情况。
```

### 3. 智能位置描述系统

系统会自动根据ROI区域的坐标生成直观的位置描述：

#### 水平位置判断
- x < 0.33 → "左侧"
- 0.33 ≤ x < 0.67 → "中央"
- x ≥ 0.67 → "右侧"

#### 垂直位置判断
- y < 0.33 → "上方"
- 0.33 ≤ y < 0.67 → "中部"
- y ≥ 0.67 → "下方"

#### 区域大小判断
- 面积 < 5% → "小区域"
- 5% ≤ 面积 < 15% → "中等区域"
- 面积 ≥ 15% → "大区域"

#### 位置描述示例
- "左侧上方的小区域"
- "中央中部的中等区域"
- "右侧下方的大区域"

## 技术实现

### 后端优化
1. **统一ROI信息处理**：无论哪种模式都添加ROI信息到提示词
2. **智能位置描述**：`getPositionDescription()` 函数自动生成位置描述
3. **模式特定指导**：根据 `sendStandardImage` 配置提供不同的检测说明
4. **动态用户文本**：根据模式调整用户消息内容

### 前端优化
1. **实时提示词预览**：显示根据配置生成的完整提示词
2. **位置描述生成**：前端也实现位置描述功能，保持一致性
3. **配置联动**：`sendStandardImage` 配置变化时实时更新提示词预览

### 数据库支持
- `sendStandardImage` 字段存储配置
- 向后兼容现有数据
- 支持布尔值存储

## 最佳实践

### 1. ROI区域标注建议
- **详细描述**：为每个ROI区域提供清晰、具体的描述
- **关键特征**：包含需要检测的关键特征和标准
- **标准化语言**：使用统一的描述语言和术语

### 2. 模式选择建议
- **简单检测**：使用仅ROI信息模式，降低成本
- **复杂检测**：使用发送标准图片模式，提高精度
- **批量检测**：优先使用仅ROI信息模式
- **关键检测**：可以使用发送标准图片模式

### 3. 测试验证
- 创建测试用例验证两种模式的效果
- 根据实际检测结果调整配置
- 定期评估ROI区域描述的准确性
