# 健康系统报告发送功能说明

## 功能概述

在洁净用品结果页面新增了"发送报告"功能，可以将检测结果自动生成报告并发送到健康系统的洁净用品穿戴检查记录中。

## 功能特点

### 1. 报告生成
- 自动整合指定时间段内的检测结果
- 生成包含统计数据的完整报告
- 支持自定义检查地点和描述信息

### 2. 数据统计
- 总检测次数
- 合格次数和存疑次数
- 合格率计算
- 详细检测记录

### 3. 用户界面
- 直观的报告预览
- 时间段选择器
- 地点输入（必填）
- 描述信息输入

## 使用方法

### 1. 访问功能
1. 进入"洁净用品结果"页面
2. 点击右上角的"发送报告"按钮
3. 填写报告信息

### 2. 填写报告信息
- **检查开始时间**: 选择检查开始的时间
- **检查结束时间**: 选择检查结束的时间
- **检查地点**: 必填，输入检查地点（如：洁净室A区、生产车间等）
- **报告描述**: 可选，输入报告描述信息

### 3. 发送报告
1. 确认信息无误后点击"发送报告"按钮
2. 系统会自动生成报告并发送到健康系统
3. 发送成功后会显示健康系统记录ID

## 健康系统集成

### 当前实现
- 使用模拟API进行测试
- 支持真实健康系统API集成
- 包含完整的错误处理机制

### 真实集成配置
在 `health_system_api.py` 中的 `simulate_health_system_api` 函数需要替换为真实的健康系统API调用：

```python
def send_to_real_health_system(report_data, config):
    """
    发送到真实健康系统的函数
    """
    import requests
    
    headers = {
        'Content-Type': 'application/json',
        'Authorization': f"Bearer {config['authentication']['token']}"
    }
    
    response = requests.post(
        config['apiUrl'] + config['endpoints']['ppeReports'],
        json=report_data,
        headers=headers,
        timeout=config['timeout']
    )
    
    return response.json()
```

### 配置参数
```json
{
  "enabled": true,
  "apiUrl": "https://health-system.example.com/api",
  "endpoints": {
    "ppeReports": "/ppe-reports",
    "status": "/status"
  },
  "authentication": {
    "type": "bearer_token",
    "token": "your_health_system_token_here"
  },
  "timeout": 30,
  "retryAttempts": 3
}
```

## 注意事项

1. **数据完整性**: 确保检测数据完整后再发送报告
2. **地点信息**: 检查地点是必填项，请准确填写
3. **时间范围**: 选择合适的时间范围以包含相关检测结果
4. **网络连接**: 发送报告需要网络连接，请确保网络正常
5. **健康系统配置**: 在生产环境中需要配置真实的健康系统API
