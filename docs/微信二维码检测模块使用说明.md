# 微信二维码检测模块使用说明

## 概述

本系统已集成微信官方的WeChatQRCode二维码检测模块，提供高精度、高效率的二维码识别功能。该模块基于OpenCV的contrib模块，具有以下特点：

- ✅ **高精度检测**：基于微信官方算法，检测精度高
- 🚀 **高效性能**：优化的检测算法，处理速度快
- 🔄 **重试机制**：支持多次重试，提高检测成功率
- 🎯 **多二维码支持**：可同时检测多个二维码
- 📊 **详细结果**：提供位置、置信度等详细信息

## 安装和配置

### 1. 安装依赖

确保已安装必要的Python依赖：

```bash
pip install opencv-contrib-python>=4.10.0.84
```

### 2. 下载模型文件

运行安装脚本自动下载模型文件：

```bash
cd backend
./install_wechat_qr_models.sh
```

或者手动下载模型文件到 `backend/models/wechat_qr/` 目录：

- `detect.prototxt`
- `detect.caffemodel`
- `sr.prototxt`
- `sr.caffemodel`

模型文件下载地址：https://github.com/WeChatCV/opencv_3rdparty

### 3. 验证安装

启动Django后端服务，访问模型状态API：

```bash
curl http://localhost:8000/api/wechat-qr/status/
```

## API接口

### 1. 基础检测API

**端点**: `POST /api/wechat-qr/detect/`

**请求体**:
```json
{
    "image": "base64编码的图片数据"
}
```

**响应**:
```json
{
    "success": true,
    "detected_codes": [
        {
            "id": 1,
            "data": "二维码内容",
            "confidence": 0.95,
            "location": {
                "x": 100,
                "y": 100,
                "width": 200,
                "height": 200
            },
            "corners": [[x1,y1], [x2,y2], [x3,y3], [x4,y4]],
            "type": "qr"
        }
    ],
    "count": 1,
    "model_used": "wechat_qr",
    "message": "检测完成信息"
}
```

### 2. 重试检测API

**端点**: `POST /api/wechat-qr/detect-with-retry/`

**请求体**:
```json
{
    "image": "base64编码的图片数据",
    "expected_codes": [
        {
            "expectedText": "期望的二维码内容",
            "matchMode": "contains"
        }
    ],
    "max_retries": 3
}
```

**响应**:
```json
{
    "success": true,
    "match_results": [
        {
            "expected_text": "期望内容",
            "match_mode": "contains",
            "matched": true,
            "detected_data": "检测到的内容",
            "confidence": 0.95,
            "location": {
                "x": 100,
                "y": 100,
                "width": 200,
                "height": 200
            },
            "retry_count": 1
        }
    ],
    "retry_summary": {
        "total_retries": 3,
        "successful_detections": 1,
        "failed_detections": 0
    },
    "model_used": "wechat_qr"
}
```

### 3. 模型状态API

**端点**: `GET /api/wechat-qr/status/`

**响应**:
```json
{
    "model_loaded": true,
    "model_path": "/path/to/models",
    "model_name": "wechat_qr",
    "available": true,
    "description": "微信二维码检测模型 (WeChatQRCode)"
}
```

## 前端使用

### 1. 基础检测

```typescript
import { detectBarcodes } from '@/lib/barcodeDetector';

// 使用微信二维码检测器
const results = await detectBarcodes(imageFile, {
  useWeChatQR: true
});
```

### 2. 重试检测

```typescript
import { detectBarcodesWithRetry } from '@/lib/barcodeDetector';

const retryResult = await detectBarcodesWithRetry(imageFile, [
  { expectedText: 'TEST', matchMode: 'contains' }
], {
  maxRetries: 3,
  useWeChatQR: true
});
```

### 3. 测试页面

访问 `/wechat-qr-test` 页面进行微信二维码检测测试：

- 上传测试图片
- 配置期望的二维码内容
- 选择检测模式（微信/前端）
- 查看详细的检测结果

## 配置选项

### BarcodeDetectorOptions

```typescript
interface BarcodeDetectorOptions {
  enableQR?: boolean;        // 启用二维码检测
  useWeChatQR?: boolean;     // 使用微信二维码检测器
  useQuagga?: boolean;       // 使用Quagga检测器
  enableBarcode?: boolean;   // 启用条形码检测
  barcodeTypes?: string[];   // 条形码类型
}
```

### RetryDetectionOptions

```typescript
interface RetryDetectionOptions {
  maxRetries?: number;       // 最大重试次数
  enableMasking?: boolean;   // 启用遮罩功能
  maskColor?: string;        // 遮罩颜色
  maskPadding?: number;      // 遮罩边距
}
```

## 故障排除

### 1. 模型加载失败

**问题**: 模型文件加载失败
**解决方案**:
- 检查模型文件是否完整下载
- 确认文件路径正确
- 检查OpenCV版本是否支持WeChatQRCode

### 2. 检测精度低

**问题**: 二维码检测精度不高
**解决方案**:
- 确保图片清晰度足够
- 调整图片对比度
- 使用重试机制

### 3. API请求失败

**问题**: 前端调用后端API失败
**解决方案**:
- 检查后端服务是否启动
- 确认API端点路径正确
- 检查CORS配置
