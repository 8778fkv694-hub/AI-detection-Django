# 挂起报告重试功能说明

## 功能概述

为发送报告功能添加了智能的挂起和重试机制，当健康系统无法响应或发送失败时，报告会自动挂起，用户可以稍后手动重试发送。

## 功能特点

### 1. 智能挂起机制
- **发送成功**: 显示成功消息，关闭对话框
- **发送失败**: 自动将报告添加到挂起列表
- **网络错误**: 网络问题也会触发挂起机制
- **用户友好**: 失败时提示用户可以在挂起列表中重试

### 2. 挂起报告管理
- **可视化列表**: 显示所有挂起的报告
- **详细信息**: 显示报告ID、地点、时间范围、错误信息
- **统计信息**: 显示检测统计数据
- **重试计数**: 记录重试次数和最后尝试时间

### 3. 手动重试功能
- **一键重试**: 点击"重试发送"按钮重新发送
- **重试计数**: 自动记录重试次数
- **错误更新**: 重试失败时更新错误信息
- **成功移除**: 重试成功后自动从挂起列表移除

### 4. 报告管理
- **删除功能**: 可以删除不需要的挂起报告
- **批量管理**: 支持管理多个挂起报告
- **状态跟踪**: 实时显示挂起报告数量

## 使用方法

### 1. 发送报告
1. 填写报告信息（地点、时间、描述等）
2. 点击"发送报告"按钮
3. 如果发送成功，显示成功消息
4. 如果发送失败，报告会自动挂起

### 2. 查看挂起报告
1. 当有挂起报告时，会显示"挂起报告 (数量)"按钮
2. 点击按钮打开挂起报告列表
3. 查看每个报告的详细信息和错误原因

### 3. 重试发送
1. 在挂起报告列表中找到要重试的报告
2. 点击"重试发送"按钮
3. 系统会重新尝试发送到健康系统
4. 成功后会从挂起列表中移除

### 4. 删除报告
1. 在挂起报告列表中找到要删除的报告
2. 点击"删除"按钮
3. 确认删除操作
4. 报告会从挂起列表中移除

              ...report,
              retryCount: report.retryCount + 1,

            }
          : report
      ));
    }

  }
};

## 错误处理

### 1. 发送失败类型
- **服务器错误**: 健康系统返回错误
- **网络错误**: 连接超时或网络问题
- **数据错误**: 请求数据格式错误
- **认证错误**: 健康系统认证失败

### 2. 错误信息显示
- **错误描述**: 显示具体的错误信息
- **错误时间**: 记录错误发生时间
- **重试建议**: 提示用户可以重试

### 3. 重试策略
- **手动重试**: 用户主动点击重试
- **重试计数**: 记录重试次数
- **错误更新**: 每次重试后更新错误信息
- **无限重试**: 不限制重试次数

## 使用场景

### 1. 网络不稳定
- 网络中断时报告自动挂起
- 网络恢复后可以重试发送
- 避免数据丢失

### 2. 健康系统维护
- 健康系统维护期间发送失败
- 维护完成后可以重试发送
- 保证数据完整性

### 3. 临时错误
- 健康系统临时错误
- 服务器负载过高
- 认证令牌过期

## 注意事项

1. **数据完整性**: 挂起的报告包含完整的发送数据
2. **重试安全**: 重试不会重复创建记录
3. **错误处理**: 详细的错误信息帮助诊断问题
4. **用户体验**: 友好的提示和操作界面
5. **性能考虑**: 挂起报告数量不宜过多
