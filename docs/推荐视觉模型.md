- **推荐指数**: ⭐⭐⭐⭐

## 🛠️ 快速安装和配置

### 安装模型
```bash
# 推荐：Qwen2.5-VL-7B
ollama pull qwen2.5-vl-7b-instruct

# 或者：LLaVA
ollama pull llava-v1.6-mistral-7b
```

### 自动配置
```bash
# 使用配置脚本自动更新
./update-vision-model.sh qwen2.5-vl-7b-instruct
```

### 手动配置
1. 安装模型后，更新以下文件中的模型名称
2. 重启Ollama服务
3. 测试模型是否正常工作

## ⚠️ 注意事项

1. **内存需求**: 7B模型需要至少8GB RAM，14B模型需要16GB+
2. **存储空间**: 确保有足够的磁盘空间
3. **响应时间**: 视觉模型比纯文本模型慢，需要耐心等待
4. **图片格式**: 支持JPEG、PNG等常见格式
5. **并发限制**: 建议单线程处理，避免内存不足

## 🔧 优化建议

1. **首次使用**: 建议先用7B模型测试
2. **生产环境**: 根据需求选择14B或更大模型
3. **资源有限**: 选择MiniCPM-V等轻量级模型
4. **中文场景**: 优先选择Qwen系列模型
