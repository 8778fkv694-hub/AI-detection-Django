# 模型管理页面 - 移动端优化说明

## 🚀 新增功能

### 📱 移动端检测
- 自动检测设备屏幕尺寸
- 当屏幕宽度 < 768px 时自动切换到移动端模式
- 实时响应窗口大小变化

### 🎯 移动端菜单
- 添加移动端模式指示器
- 显示智能手机图标和"移动端模式"标签
- 顶部显示移动端状态栏

### 🔄 卡片折叠功能
- 移动端下模型卡片默认收起，只显示基本信息
- 点击展开/收起按钮（▼/▲）可展开/收起详细内容
- 节省屏幕空间，提升浏览体验

### 📐 响应式布局
- **桌面端**: 3列网格布局，完整显示所有信息
- **移动端**: 单列垂直布局，卡片可折叠
- 自动调整字体大小、间距和图标尺寸

## 🎨 界面优化

### 标题和按钮
- 移动端标题字体从 `text-3xl` 调整为 `text-2xl`
- 刷新按钮在移动端下占满宽度，便于触摸操作

### 模型卡片
- 移动端下徽章字体调整为 `text-xs`
- 模型参数在移动端下改为单列布局，左右对齐显示
- 支持的类别在移动端下最多显示3个（桌面端5个）

### 统计卡片
- 移动端下图标从 `h-8 w-8` 调整为 `h-6 w-6`
- 数字字体从 `text-2xl` 调整为 `text-xl`
- 描述文字从 `text-sm` 调整为 `text-xs`
- 内边距从 `p-4` 调整为 `p-3`

## 📱 触摸优化

### 按钮尺寸
- 所有交互按钮都经过触摸友好设计
- 展开/收起按钮使用 `h-4 w-4` 图标，便于点击

### 间距调整
- 移动端下卡片间距从 `gap-4` 调整为 `space-y-3`
- 统计卡片间距从 `gap-4` 调整为 `gap-3`

## 🔧 技术实现

### 状态管理
```typescript
// 移动端状态
const [isMobile, setIsMobile] = useState(false);
const [expandedCards, setExpandedCards] = useState<Set<string>>(new Set());

// 检测移动端
useEffect(() => {
  const checkMobile = () => {
    setIsMobile(window.innerWidth < 768);
  };
  
  checkMobile();
  window.addEventListener('resize', checkMobile);
  
  return () => window.removeEventListener('resize', checkMobile);
}, []);
```

### 响应式样式
```typescript
// 使用 cn() 函数动态应用样式
className={cn(
  "gap-4",
  isMobile ? "space-y-3" : "grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3"
)}
```

### 卡片折叠逻辑
```typescript
// 切换卡片展开状态
const toggleCardExpansion = (modelId: string) => {
  const newExpanded = new Set(expandedCards);
  if (newExpanded.has(modelId)) {
    newExpanded.delete(modelId);
  } else {
    newExpanded.add(modelId);
  }
  setExpandedCards(newExpanded);
};
```

## 📱 使用说明

### 移动端用户
1. **查看模型列表**: 页面自动适配移动端布局
2. **展开模型详情**: 点击卡片右上角的 ▼ 按钮展开详细信息
3. **收起模型详情**: 点击 ▲ 按钮收起详细信息
4. **切换模型**: 点击"切换到此模型"按钮

### 桌面端用户
- 保持原有的完整布局和功能
- 所有信息默认展开显示
- 3列网格布局，充分利用屏幕空间

## 🎯 性能优化

### 条件渲染
- 移动端下隐藏不必要的详细信息，减少DOM节点
- 使用 `hidden` 类而不是完全移除元素，保持状态

### 响应式图片
- 图标尺寸根据设备自动调整
- 避免在小屏幕上显示过大的图标
