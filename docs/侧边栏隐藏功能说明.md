# 侧边栏隐藏功能说明

## 🚀 新增功能

### 🎯 侧边栏切换按钮
- 在页面左侧中间位置添加了一个极简扁平化箭头按钮
- 使用SVG图标：向左箭头（隐藏侧边栏）和向右箭头（显示侧边栏）
- 按钮位置固定在左侧，始终可见

### 🔄 侧边栏状态管理
- **显示状态**: 侧边栏宽度为 `w-64`（256px），完全可见
- **隐藏状态**: 侧边栏宽度为 `w-0`，内容透明化
- 状态通过 `useState` 管理，支持实时切换

### ✨ 动画效果
- 所有状态变化都有平滑的过渡动画
- 侧边栏宽度变化：`transition-all duration-300 ease-in-out`
- 内容透明度变化：`transition-opacity duration-300`
- 主内容区域内边距调整：`transition-all duration-300 ease-in-out`

## 🎨 界面设计

### 切换按钮样式
```typescript
className={cn(
  "fixed left-0 top-1/2 z-50 h-12 w-6 -translate-y-1/2 rounded-r-lg border border-l-0 border-border/50 bg-background/80 backdrop-blur-sm transition-all duration-300 hover:bg-background/90",
  sidebarVisible ? "left-64" : "left-0",
  "flex items-center justify-center p-0"
)}
```

**特性**:
- **位置**: `fixed left-0 top-1/2` - 固定在左侧中间
- **尺寸**: `h-12 w-6` - 高度48px，宽度24px
- **样式**: 圆角右侧，半透明背景，毛玻璃效果
- **悬停**: 鼠标悬停时背景变深
- **图标**: 极简扁平化SVG箭头，支持主题色彩

### 侧边栏样式
```typescript
className={cn(
  "border-r border-border/50 bg-background/50 backdrop-blur-sm transition-all duration-300 ease-in-out",
  sidebarVisible ? "w-64" : "w-0 -ml-4",
  "relative"
)}
```

**特性**:
- **宽度变化**: `w-64`（256px）↔ `w-0`（0px）
- **边距调整**: 隐藏时使用 `-ml-4` 减少空白
- **过渡效果**: 300ms的缓入缓出动画

### 主内容区域
```typescript
className={cn(
  "flex-1 overflow-y-auto transition-all duration-300 ease-in-out",
  sidebarVisible ? "p-8" : "p-4 pl-8"
)}
```

**特性**:
- **内边距调整**: 侧边栏隐藏时减少内边距
- **左侧间距**: 始终保留 `pl-8` 为切换按钮留出空间

## 🎨 图标设计

### 极简扁平化风格
- **设计理念**: 采用现代极简主义设计语言
- **线条风格**: 2px描边，圆角端点，简洁清晰
- **色彩适配**: 使用 `currentColor` 自动适配主题色彩
- **尺寸规格**: 16x16px，适合各种屏幕密度

### SVG技术优势
- **矢量图形**: 任意缩放不失真
- **主题支持**: 自动继承当前文字颜色
- **性能优化**: 轻量级，渲染效率高
- **可访问性**: 支持屏幕阅读器

### 动画效果
- **旋转动画**: 图标根据侧边栏状态旋转180度
- **平滑过渡**: 300ms缓入缓出动画
- **视觉反馈**: 清晰的状态指示

## 🔧 技术实现

### 状态管理
```typescript
const [sidebarVisible, setSidebarVisible] = useState(true);

const toggleSidebar = () => {
  setSidebarVisible(!sidebarVisible);
};
```

### 条件样式
```typescript
// 侧边栏宽度
sidebarVisible ? "w-64" : "w-0 -ml-4"

// 切换按钮位置
sidebarVisible ? "left-64" : "left-0"

// 主内容内边距
sidebarVisible ? "p-8" : "p-4 pl-8"
```

### 图标切换
```typescript
<svg
  className={cn(
    "h-4 w-4 transition-transform duration-300",
    sidebarVisible ? "rotate-0" : "rotate-180"
  )}
  fill="none"
  stroke="currentColor"
  strokeWidth="2"
  strokeLinecap="round"
  strokeLinejoin="round"
  viewBox="0 0 24 24"
>
  {sidebarVisible ? (
    // 向左箭头 - 隐藏侧边栏
    <path d="M15 18l-6-6 6-6" />
  ) : (
    // 向右箭头 - 显示侧边栏
    <path d="M9 18l6-6-6-6" />
  )}
</svg>
```
