# 健康系统动态IP配置功能说明

## 功能概述

为了解决健康系统在局域网中IP地址会变化的问题，我们为AI检测系统添加了智能的健康系统配置功能，支持自动发现和手动配置两种模式。

## 主要特性

### 1. 自动发现模式
- **智能扫描**: 自动扫描局域网中的所有IP地址（端口4003）
- **并发检测**: 使用多线程并发扫描，提高发现速度
- **实时状态**: 显示健康系统的连接状态和详细信息

### 2. 手动配置模式
- **IP地址配置**: 手动输入健康系统的IP地址和端口
- **连接测试**: 实时测试与健康系统的连接状态
- **配置保存**: 保存配置到后端，下次启动时自动应用

### 3. 用户界面
- **配置按钮**: 在发送报告页面添加"健康系统配置"按钮
- **状态显示**: 在报告发送对话框中显示健康系统连接状态
- **配置对话框**: 提供直观的配置界面

## 使用方法

### 1. 访问配置功能

#### 方法一：通过发送报告页面
1. 进入"洁净用品结果"页面
2. 点击右上角的"健康系统配置"按钮
3. 打开健康系统配置对话框

#### 方法二：通过报告发送对话框
1. 点击"发送报告"按钮
2. 在报告发送对话框中点击"健康系统状态"区域的"配置"按钮

### 2. 配置选项

#### 自动发现模式（推荐）
1. 选择"自动发现健康系统"选项
2. 点击"扫描网络"按钮
3. 系统会自动扫描局域网中的健康系统
4. 如果发现健康系统，会自动配置并测试连接

#### 手动配置模式
1. 选择"手动配置IP地址"选项
2. 输入健康系统的IP地址（例如：192.168.1.100）
3. 输入端口号（默认：4003）
4. 点击"测试连接"按钮验证连接
5. 点击"保存配置"按钮保存设置

### 3. 状态监控

#### 连接状态指示器
- **绿色圆点**: 健康系统已连接
- **红色圆点**: 健康系统未连接

#### 状态信息
- 显示详细的连接状态信息
- 显示最后检查时间
- 显示错误信息（如果有）

## 故障排除

### 1. 扫描不到健康系统
**可能原因**:
- 健康系统未启动
- 健康系统运行在其他端口
- 网络连接问题
- 防火墙阻止连接

**解决方法**:
1. 检查健康系统是否运行在端口4003
2. 尝试手动配置IP地址
3. 检查网络连接
4. 检查防火墙设置

### 2. 连接测试失败
**可能原因**:
- IP地址错误
- 端口号错误
- 健康系统未响应
- 认证失败

**解决方法**:
1. 验证IP地址和端口号
2. 检查健康系统状态
3. 验证认证token
4. 查看错误信息

### 3. 配置保存失败
**可能原因**:
- 后端服务未启动
- 权限问题
- 配置文件损坏

**解决方法**:
1. 检查Django后端服务
2. 检查文件权限
3. 重新创建配置文件

- 确保AI检测系统和健康系统在同一局域网
- 配置静态IP地址（如果可能）
- 开放必要的端口（4003）

### 2. 安全配置

- 控制并发扫描数量
- 定期清理无效配置

## 注意事项

1. **网络扫描**: 自动扫描会检查整个网段，可能需要几秒钟时间
2. **并发限制**: 默认使用50个并发连接，可根据网络情况调整
3. **超时设置**: 默认连接超时为2秒，可根据网络延迟调整
4. **配置持久化**: 配置会保存到文件中，重启后自动加载
5. **错误处理**: 详细的错误信息帮助诊断问题
