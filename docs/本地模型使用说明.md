# 本地模型使用说明

## 界面更新说明

根据您的要求，本地模型页面已经更新：

### ✅ 已移除的功能
- **启动服务按钮** - 不再通过网页启动Ollama服务
- **停止服务按钮** - 不再通过网页停止Ollama服务

### ✅ 保留的功能
- **刷新状态按钮** - 检查Ollama服务运行状态
- **测试模型按钮** - 测试本地模型连接和响应
- **配置保存** - 保存模型配置参数

### ✅ 新增的指引
- **启动指引按钮** - 点击显示终端启动命令
- **详细指引信息** - 页面中显示完整的启动步骤
- **一键复制功能** - 每个命令旁边都有复制按钮，点击即可复制到剪贴板

## 使用方法

### 1. 启动Ollama服务（终端方式）

**方法一：直接启动**
```bash
ollama serve
```
> 💡 在网页上点击命令旁边的复制按钮，然后粘贴到终端

**方法二：使用项目脚本**
```bash
./start_mac.sh ollama-proxy
```
> 💡 在网页上点击命令旁边的复制按钮，然后粘贴到终端

**方法三：仅启动Ollama**
```bash
./start_mac.sh ollama
```
> 💡 在网页上点击命令旁边的复制按钮，然后粘贴到终端

### 2. 检查服务状态

1. 打开本地模型配置页面
2. 点击"刷新状态"按钮
3. 查看服务状态和可用模型

### 3. 测试模型

1. 确保Ollama服务正在运行
2. 点击"测试模型"按钮
3. 查看模型响应结果

## 服务地址

- **Ollama服务**: `http://localhost:11434`
- **HTTP代理**: `http://localhost:11435`
- **后端API**: `http://localhost:8000`

## 故障排除

### 服务启动失败
```bash
# 检查Ollama是否安装
ollama --version

# 检查端口占用
lsof -i :11434

# 手动启动
ollama serve
```

### 状态检查失败
1. 确保Ollama服务正在运行
2. 检查代理服务是否启动
3. 刷新页面重试

### 模型测试失败
1. 确保模型已下载：`ollama pull qwen2.5-vl-7b`
2. 检查模型名称配置
3. 查看终端错误信息

现在您可以通过终端稳定地启动Ollama服务，然后在网页上进行状态检查和模型测试！
