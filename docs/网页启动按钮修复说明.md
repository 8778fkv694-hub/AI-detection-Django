# 网页启动按钮修复说明

## 问题描述
网页上的Ollama服务启动按钮无效，只是模拟启动，没有真正启动Ollama服务。

## 解决方案

### 1. 创建后端API
- 创建了 `backend/inspection/ollama_api.py` 文件
- 实现了三个API端点：
  - `POST /api/ollama/start/` - 启动Ollama服务
  - `POST /api/ollama/stop/` - 停止Ollama服务  
  - `GET /api/ollama/status/` - 检查服务状态

### 2. 更新URL配置
- 在 `backend/config/urls.py` 中添加了Ollama API路由
- 确保API端点可以被前端访问

### 3. 修复前端功能
- 更新了 `src/screens/LocalModelScreen.tsx`
- 启动按钮现在会调用真实的后端API
- 停止按钮也会调用真实的后端API
- 状态检查通过后端API进行

## API功能说明

### 启动Ollama服务 (`POST /api/ollama/start/`)
- 检查Ollama是否已安装
- 检查服务是否已在运行
- 使用nohup在后台启动Ollama服务
- 等待服务启动并验证
- 返回启动状态和进程ID

### 停止Ollama服务 (`POST /api/ollama/stop/`)
- 查找Ollama进程
- 优雅终止进程
- 返回停止状态

### 检查服务状态 (`GET /api/ollama/status/`)
- 检查Ollama服务是否运行
- 获取可用模型列表
- 返回详细状态信息

## 使用方法

### 1. 启动后端服务
```bash
cd backend
python manage.py runserver
```

### 2. 启动前端服务
```bash
npm run dev
```

### 3. 在网页中使用
1. 打开本地模型配置页面
2. 点击"启动Ollama服务"按钮
3. 等待服务启动完成
4. 查看服务状态和可用模型

## 注意事项

1. **Ollama安装**: 确保系统已安装Ollama
2. **权限问题**: 确保有足够权限启动和停止进程
3. **端口冲突**: 确保11434端口未被占用
4. **依赖安装**: 后端需要安装psutil库

## 故障排除

### 启动失败
- 检查Ollama是否已安装: `ollama --version`
- 检查端口是否被占用: `lsof -i :11434`
- 查看后端日志获取详细错误信息

### 状态检查失败
- 确保后端服务正在运行
- 检查API端点是否正确配置
- 验证网络连接

### 权限问题
- 确保有启动进程的权限
- 检查文件系统权限
- 考虑使用sudo（不推荐）

现在网页上的启动按钮应该可以正常工作了！
