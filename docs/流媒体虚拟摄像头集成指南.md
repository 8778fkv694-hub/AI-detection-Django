# 流媒体虚拟摄像头集成指南

本指南说明如何在检测页面中集成流媒体虚拟摄像头功能。

## 功能概述

通过流媒体虚拟摄像头功能，用户可以：
1. 在流媒体管理页面添加和管理流媒体源（RTSP、RTMP、HTTP等）
2. 在各个检测页面的摄像头下拉框中看到这些虚拟摄像头
3. 选择虚拟摄像头后，显示来自流媒体的实时画面
4. 像使用普通摄像头一样进行检测

## 后端API

### 流媒体管理API

- `GET /api/streams/` - 获取所有流媒体源
- `POST /api/streams/` - 创建流媒体源
- `GET /api/streams/{id}/` - 获取单个流媒体源
- `PATCH /api/streams/{id}/` - 更新流媒体源
- `DELETE /api/streams/{id}/` - 删除流媒体源
- `POST /api/streams/{id}/start/` - 启动流媒体
- `POST /api/streams/{id}/stop/` - 停止流媒体
- `GET /api/streams/{id}/status/` - 获取流媒体状态
- `GET /api/streams/{id}/frame/?quality=85` - 获取当前帧（Base64编码）
- `GET /api/streams/active_streams/` - 获取所有激活的流媒体

## 前端集成步骤

### 步骤1: 使用 useVirtualCameras Hook

在检测页面中导入并使用 `useVirtualCameras` Hook：

```typescript
import { useVirtualCameras } from '@/hooks/useVirtualCameras';

// 在组件中使用
const YourDetectionScreen = () => {
  // 获取所有摄像头（真实+虚拟）
  const { allCameras, virtualCameras, realCameras, refreshCameras } = useVirtualCameras({
    refreshInterval: 10000, // 每10秒刷新一次
    autoRefresh: true,
  });

  const [selectedDeviceId, setSelectedDeviceId] = useState('');
  const [selectedCamera, setSelectedCamera] = useState<VirtualCameraDevice | null>(null);
  
  // ... 其他代码
};
```

### 步骤2: 更新摄像头选择下拉框

```typescript
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@/components/ui/Select';
import type { VirtualCameraDevice } from '@/types/stream';

// 在JSX中
<Select 
  value={selectedDeviceId} 
  onValueChange={(deviceId) => {
    setSelectedDeviceId(deviceId);
    
    // 找到选中的摄像头
    const camera = allCameras.find(c => c.deviceId === deviceId);
    setSelectedCamera(camera || null);
  }}
>
  <SelectTrigger className="w-48">
    <SelectValue placeholder="选择摄像头" />
  </SelectTrigger>
  <SelectContent>
    {allCameras.map(camera => (
      <SelectItem key={camera.deviceId} value={camera.deviceId}>
        {camera.label}
        {camera.isVirtual && <span className="text-xs text-blue-500 ml-2">流媒体</span>}
      </SelectItem>
    ))}
  </SelectContent>
</Select>
```

### 步骤3: 处理视频显示

根据选中的摄像头类型，使用不同的视频显示方式：

```typescript
import VirtualCameraVideo from '@/components/VirtualCameraVideo';

// 在组件中
const videoRef = useRef<HTMLVideoElement>(null);
const [isCameraOn, setIsCameraOn] = useState(false);

// 启动摄像头
const startCamera = async () => {
  if (!selectedCamera) return;
  
  if (selectedCamera.isVirtual) {
    // 虚拟摄像头：不需要特殊处理，由VirtualCameraVideo组件处理
    setIsCameraOn(true);
  } else {
    // 真实摄像头：使用getUserMedia
    try {
      const stream = await navigator.mediaDevices.getUserMedia({
        video: { deviceId: { exact: selectedCamera.deviceId } }
      });
      if (videoRef.current) {
        videoRef.current.srcObject = stream;
      }
      setIsCameraOn(true);
    } catch (err) {
      console.error('启动摄像头失败:', err);
    }
  }
};

// 停止摄像头
const stopCamera = () => {
  if (videoRef.current?.srcObject) {
    const stream = videoRef.current.srcObject as MediaStream;
    stream.getTracks().forEach(track => track.stop());
    videoRef.current.srcObject = null;
  }
  setIsCameraOn(false);
};

// 在JSX中显示视频
return (
  <div className="relative">
    {/* 真实摄像头的video元素 */}
    <video
      ref={videoRef}
      autoPlay
      playsInline
      muted
      className="w-full h-full"
      style={{ display: selectedCamera?.isVirtual ? 'none' : 'block' }}
    />
    
    {/* 虚拟摄像头的canvas元素 */}
    {selectedCamera?.isVirtual && selectedCamera.streamId && (
      <VirtualCameraVideo
        streamId={selectedCamera.streamId}
        enabled={isCameraOn}
        fps={15}
        quality={85}
        className="w-full h-full"
        onError={(error) => {
          console.error('虚拟摄像头错误:', error);
          toast.error('虚拟摄像头错误: ' + error);
        }}
      />
    )}
  </div>
);
```

### 步骤4: 捕获帧进行检测

无论是真实摄像头还是虚拟摄像头，都可以使用相同的方式捕获帧：

```typescript
const captureFrame = (): string | null => {
  // 对于真实摄像头
  if (!selectedCamera?.isVirtual && videoRef.current) {
    const video = videoRef.current;
    const canvas = document.createElement('canvas');
    canvas.width = video.videoWidth;
    canvas.height = video.videoHeight;
    const ctx = canvas.getContext('2d');
    if (ctx) {
      ctx.drawImage(video, 0, 0);
      return canvas.toDataURL('image/jpeg', 0.9);
    }
  }
  
  // 对于虚拟摄像头
  if (selectedCamera?.isVirtual) {
    // 虚拟摄像头使用canvas，可以直接获取
    const canvas = document.querySelector('canvas[data-virtual-camera]') as HTMLCanvasElement;
    if (canvas) {
      return canvas.toDataURL('image/jpeg', 0.9);
    }
  }
  
  return null;
};
```

## 注意事项

1. **性能优化**：虚拟摄像头默认使用15 FPS，可以根据需要调整
2. **网络延迟**：流媒体可能存在网络延迟，建议在本地网络使用
3. **错误处理**：流媒体连接可能失败，需要妥善处理错误情况
4. **资源清理**：组件卸载时要清理定时器和停止流媒体

## 快速集成模板

以下是一个最小化的集成模板，可以复制到任何检测页面：

```typescript
import { useVirtualCameras } from '@/hooks/useVirtualCameras';
import VirtualCameraVideo from '@/components/VirtualCameraVideo';
import type { VirtualCameraDevice } from '@/types/stream';

const YourScreen = () => {
  const { allCameras } = useVirtualCameras();
  const [selectedDeviceId, setSelectedDeviceId] = useState('');
  const [selectedCamera, setSelectedCamera] = useState<VirtualCameraDevice | null>(null);
  const videoRef = useRef<HTMLVideoElement>(null);
  
  // 选择摄像头时更新selectedCamera
  const handleCameraChange = (deviceId: string) => {
    setSelectedDeviceId(deviceId);
    const camera = allCameras.find(c => c.deviceId === deviceId);
    setSelectedCamera(camera || null);
  };
  
  return (
    <>
      {/* 摄像头选择 */}
      <Select value={selectedDeviceId} onValueChange={handleCameraChange}>
        <SelectTrigger>
          <SelectValue placeholder="选择摄像头" />
        </SelectTrigger>
        <SelectContent>
          {allCameras.map(camera => (
            <SelectItem key={camera.deviceId} value={camera.deviceId}>
              {camera.label}
            </SelectItem>
          ))}
        </SelectContent>
      </Select>
      
      {/* 视频显示 */}
      <div className="relative">
        <video
          ref={videoRef}
          autoPlay
          playsInline
          muted
          style={{ display: selectedCamera?.isVirtual ? 'none' : 'block' }}
        />
        {selectedCamera?.isVirtual && selectedCamera.streamId && (
          <VirtualCameraVideo
            streamId={selectedCamera.streamId}
            enabled={true}
            fps={15}
            quality={85}
          />
        )}
      </div>
    </>
  );
};
```

## 故障排查

### 问题1：虚拟摄像头不显示在列表中
- 检查流媒体是否已启用（enabled=true）
- 检查流媒体状态是否为active
- 检查后端API是否正常运行

### 问题2：虚拟摄像头画面黑屏
- 检查流媒体URL是否正确
- 检查网络连接
- 查看浏览器控制台错误信息
- 检查后端日志

### 问题3：画面卡顿
- 降低FPS（建议10-15 FPS）
- 降低画质quality参数（建议70-85）
- 检查网络带宽
