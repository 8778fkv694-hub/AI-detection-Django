# 模型检测类型统一管理说明

## 概述

已将模型与检测类型的映射关系统一到后端管理，前端可以通过API获取，避免硬编码。

## 实现内容

### 1. 后端配置（`backend/inspection/model_config.py`）

为每个模型添加了 `detection_type` 字段：

| 模型ID | 模型名称 | 检测类型 | 说明 |
|--------|---------|---------|------|
| `ppe_detection` | PPE检测专用模型 | `cleanroom_ppe` | 洁净用品检测 |
| `yolo8_general` | YOLO8通用检测模型 | `general_quality` | 通用质量检测 |
| `filter_core_detection` | 滤芯专用检测模型 | `kit_matching` | 齐套化检测 |
| `waterprifer_detection` | 净水机专用检测模型 | `ocr_inspection` | OCR检测 |

### 3. 前端API（`src/lib/api.ts`）

#### 3.1 类型定义
```typescript
export interface ModelConfig {
  id: string;
  name: string;
  file: string;
  description: string;
  classes: string[];
  detection_type: 'cleanroom_ppe' | 'standard_inspection' | 'general_quality' | 
                  'ocr_inspection' | 'ocr_fusion_inspection' | 'kit_matching' | 'unknown';
  confidence_threshold: number;
  iou_threshold: number;
  is_default: boolean;
  category: string;
  file_size: number;
  exists: boolean;
}
```

#### 3.2 API函数

**获取所有模型列表（已更新）：**
```typescript
export async function getAvailableModels(): Promise<{
  models: Array<ModelConfig>;
  current_model: string;
  message: string;
}>
```

**获取模型配置（新函数）：**
```typescript
export async function getModelConfig(modelId?: string): Promise<{
  model?: ModelConfig;
  models?: Array<ModelConfig>;
  message: string;
}>
```

## 使用示例

### 前端使用示例

```typescript
import { getAvailableModels, getModelConfig } from '@/lib/api';

// 获取所有模型（包含检测类型）
const { models } = await getAvailableModels();
models.forEach(model => {
  console.log(`${model.name}: ${model.detection_type}`);
  console.log(`类别: ${model.classes.join(', ')}`);
});

// 获取单个模型配置
const { model } = await getModelConfig('ppe_detection');
if (model) {
  console.log(`检测类型: ${model.detection_type}`);
  console.log(`可用类别: ${model.classes}`);
}
```

## 迁移指南

### 前端代码迁移

**之前（硬编码）：**
```typescript
const getAvailableTargets = () => {
  if (currentModel === 'filter_core_detection') {
    return ['filter', 'name_MCF', ...];
  } else if (currentModel === 'waterprifer_detection') {
    return ['anti_counterfeit_label', ...];
  }
  // ...
};
```

**现在（从API获取）：**
```typescript
import { getModelConfig } from '@/lib/api';

const getAvailableTargets = async () => {
  const { model } = await getModelConfig(currentModel);
  return model?.classes || [];
};
```

## 检测类型说明

| 检测类型 | 说明 | 对应模型 |
|---------|------|---------|
| `cleanroom_ppe` | 洁净用品检测 | ppe_detection |
| `general_quality` | 通用质量检测 | yolo8_general |
| `kit_matching` | 齐套化检测 | filter_core_detection |
| `ocr_inspection` | OCR检测 | waterprifer_detection |
| `standard_inspection` | 标准检测 | - |
| `ocr_fusion_inspection` | OCR融合检测 | - |
| `unknown` | 未知类型 | - |

## 向后兼容性

- ✅ `getAvailableModels()` 接口保持向后兼容，只是新增了 `detection_type` 字段
- ✅ 现有前端代码可以继续使用，不会破坏
- ✅ 新的 `getModelConfig()` 接口是可选的，不影响现有功能
