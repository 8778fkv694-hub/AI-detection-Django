## 🔴 第四优先级：高复杂度通用模块

### 阶段 9: YOLO 检测 Hook（核心功能）

**目标**: 减少 **~470 行**代码

#### 步骤 9.1: 设计 Hook 接口

**建议接口**：

```typescript
interface YoloDetectionConfig {
  // 必需参数
  videoRef: RefObject<HTMLVideoElement>;
  isActive: boolean;
  detectionConfidence: number;
  selectedTargets: string[];
  
  // 检测模式
  mode: 'or' | 'and';
  timeoutSeconds?: number;
  
  // 回调函数
  onDetect: (detections: BackendYoloDetection[]) => void;
  onTriggerCapture?: (image: string, detections: BackendYoloDetection[]) => void;
  
  // 可选配置
  autoCapture?: boolean;
  imageSaveMode?: 'full' | 'roi';
  compressImage?: (image: string) => Promise<string>;
  cropImageToROI?: (image: string, detections: BackendYoloDetection[]) => Promise<string>;
}
```

interface CameraConfig {

  windowId: string;
