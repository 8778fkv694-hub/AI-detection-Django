# AI检测项目启动说明

## 项目概述

本项目是一个完整的AI检测系统，包含：
- **Django后端**: 提供AI检测API服务，运行在8000端口
- **React前端**: 提供用户界面，运行在3303端口
- **数据同步**: 自动同步检测结果和配置数据

## 快速启动

### 方法1: Mac 开发机双击入口（推荐）

```bash
/Users/yiliwen/项目快速启动/4启动AI检测项目.command
```

这是当前本机开发机的正式入口，会进入本项目并调用 `./start_mac.sh full`。

### 方法2: 命令行启动完整项目

```bash
./start_mac.sh full
```

这将同时启动Django后端和React前端，适合开发环境。

兼容旧文档的入口仍可用：

```bash
./start_full_project.sh
```

### 方法3: 只启动Django后端

```bash
./start_mac.sh django
```

这只启动Django后端，适合只需要API服务的场景。

兼容旧文档的入口仍可用：

```bash
./start_django_only.sh
```

### 方法4: Jetson / Android

```bash
# Jetson Orin Nano
bash deploy/start_jetson.sh

# Android 平板/手机
cd android-app && bash scripts/build-apk.sh debug
```

### 方法5: 手动启动

#### 启动Django后端

```bash
./start_mac.sh django
```

#### 启动React前端

```bash
./start_mac.sh frontend
```

## 访问地址

- **前端界面**: http://localhost:3303
- **后端API**: http://localhost:8000/api/
- **管理后台**: http://localhost:8000/admin

## API接口

### 主要接口

- `GET /api/standards/` - 获取检测标准
- `POST /api/standards/` - 创建检测标准
- `GET /api/results/` - 获取检测结果
- `POST /api/results/` - 保存检测结果
- `GET /api/sync/status/` - 获取同步状态

### PPE检测接口

- `POST /api/results/save-ppe-detection/` - 保存PPE检测结果
- `GET /api/results/ppe-stats/` - 获取PPE检测统计
- `GET /api/results/cleanroom-results/` - 获取洁净用品检测结果

## 数据同步机制

### 自动同步
- 前端每30秒自动同步数据
- 支持实时数据更新
- 多设备数据一致性

### 手动同步
- 支持强制数据同步
- 数据一致性检查
- 同步状态监控

## 停止服务

```bash
./start_mac.sh stop
```

或者按 `Ctrl+C` 停止当前运行的服务。

## 故障排除

### 常见问题

1. **端口被占用**
   ```bash
   lsof -i :8000  # 检查8000端口
   lsof -i :3303  # 检查3303端口
   ```

2. **依赖安装失败**
   ```bash
   # 清理并重新安装
   rm -rf node_modules package-lock.json
   npm install
   ```

3. **数据库问题**
   ```bash
   cd backend
   python3 manage.py migrate --run-syncdb
   ```

### 日志文件

- Django后端日志: `django.log`
- React前端日志: `react.log`

## 开发环境

### 系统要求

- Python 3.8+
- Node.js 16+
- npm 8+

### 环境变量

项目使用默认配置，无需额外环境变量设置。

## 部署说明

### 生产环境

1. 修改Django设置中的DEBUG和ALLOWED_HOSTS
2. 配置生产数据库（PostgreSQL/MySQL）
3. 使用Gunicorn或uWSGI部署Django
4. 使用Nginx配置静态文件和反向代理

### Docker部署

```bash
docker-compose up -d
```

## 技术支持

1. 日志文件中的错误信息
2. 网络连接和端口配置
3. 依赖版本兼容性
4. 数据库连接状态
