# Django后端数据同步机制说明

## 概述

本项目已经完全移除了Node.js后端，所有数据现在都统一保存在Django后端。系统实现了完整的数据同步机制，确保不同设备（手机端、电脑端）可以实时同步访问检测结果。

## 系统架构

### 后端架构
- **Django后端**: 运行在8000端口，提供完整的API服务
- **数据库**: SQLite数据库，存储所有检测结果和配置
- **缓存系统**: 使用Django内置缓存，提高数据访问性能
- **中间件**: 数据一致性、数据库锁、自动同步、性能监控

### 前端架构
- **React前端**: 运行在3002端口，提供用户界面
- **状态管理**: 使用Zustand管理应用状态
- **数据同步**: 每30秒自动同步数据，确保最新状态

## 数据同步机制

### 1. 自动同步
- **频率**: 每30秒自动同步一次
- **触发条件**: 前端检测到数据变化或定时触发
- **同步内容**: 检测结果、标准配置、统计数据

### 2. 手动同步
- **状态检查**: 访问 `/api/sync/status/` 查看同步状态
- **强制同步**: 调用 `/api/sync/force/` 强制执行同步
- **管理命令**: 使用 `python manage.py sync_data` 执行同步

### 3. 数据一致性保证
- **中间件检查**: 每个请求都会检查数据一致性
- **数据库锁**: 防止并发写入冲突
- **缓存管理**: 智能缓存策略，确保数据新鲜度

## 使用方法

### 手机端
1. 正常进行检测，结果会自动保存到Django后端
2. 检测完成后，数据立即同步到数据库
3. 支持离线检测，联网后自动同步

### 电脑端
1. 打开检测结果页面，数据会自动同步
2. 支持实时查看最新检测结果
3. 可以导出检测报表和统计数据

### 实时更新
- 数据每30秒自动同步，确保最新状态
- 支持多设备同时访问，数据实时同步
- 网络异常时自动重试，确保数据不丢失

## 管理命令

### 数据同步命令
```bash
# 进入Django后端目录
cd backend

# 执行数据同步
python manage.py sync_data

# 强制同步（忽略时间限制）
python manage.py sync_data --force

# 清理旧数据并同步
python manage.py sync_data --clean-old

# 清理指定天数前的数据
python manage.py sync_data --clean-old --days 7
```

### 命令参数说明
- `--clean-old`: 清理过期数据
- `--force`: 强制同步，忽略时间限制
- `--days`: 指定清理多少天前的数据（默认30天）

## 性能优化

### 1. 缓存策略
- **数据缓存**: 检测结果缓存1小时
- **统计缓存**: 统计数据缓存5分钟
- **连接缓存**: 数据库连接复用

### 2. 数据库优化
- **索引优化**: 关键字段建立索引
- **查询优化**: 使用select_related减少查询次数
- **分页查询**: 大量数据使用分页加载

### 3. 中间件优化
- **性能监控**: 记录慢请求和性能指标
- **自动清理**: 定期清理过期数据和缓存
- **连接池**: 数据库连接池管理

## 故障排除

### 1. 同步失败
- 检查网络连接
- 查看Django后端日志
- 使用 `/api/sync/status/` 检查状态

### 2. 数据不一致
- 调用 `/api/sync/force/` 强制同步
- 检查数据库连接状态
- 清理浏览器缓存

### 3. 性能问题
- 检查数据库索引
- 查看性能监控数据
- 清理过期数据
