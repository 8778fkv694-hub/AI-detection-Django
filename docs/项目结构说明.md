# AI检测项目 - 目录结构说明

## 📁 项目根目录结构

### 🚀 核心启动文件
- `启动AI检测项目.command` - 主启动脚本（macOS）
- `停止AI检测项目.command` - 停止脚本（macOS）
- `setup_environment.sh` - 环境设置脚本
- `activate_venv.sh` - 虚拟环境激活脚本

#### `logs/` - 日志文件
- 应用运行日志

#### `config_files/` - 配置文件

- 环境配置

#### `reports/` - 报告文件

## 📋 使用说明

### 启动项目
```bash
# 使用主启动脚本
./启动AI检测项目.command

# 或手动启动
source venv/bin/activate
./启动AI检测项目.command
```

### 环境设置
```bash
# 重新设置环境
./setup_environment.sh
```

### 查看文档
```bash
# 查看项目文档
ls docs/
```

### 查看日志
```bash
# 查看运行日志
ls logs/
```

## 🔍 故障排除

### 常见问题
1. **导入错误**: 检查 `vite.config.ts` 中的路径别名配置
2. **依赖问题**: 重新运行 `./setup_environment.sh`
3. **端口冲突**: 检查 `8000`, `3001`, `3002`, `3303` 端口是否被占用

### 清理和重建
```bash
# 清理虚拟环境
rm -rf venv/
./setup_environment.sh

# 清理日志
rm -rf logs/*
```
