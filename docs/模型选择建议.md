## 🔧 内存优化建议

### 1. **使用CPU模式**
```bash
# 设置环境变量
export OLLAMA_NUM_GPU=0
export OLLAMA_NUM_THREAD=2
```

### 2. **限制上下文长度**
```json
{
  "num_ctx": 4096,  // 减少上下文长度
  "num_predict": 512,  // 限制输出长度
  "f16_kv": true,  // 使用半精度
  "low_vram": true  // 低显存模式
}
```

### 3. **图片压缩**
- 将图片压缩到512x512像素
- 使用JPEG格式，质量0.7
- 减少base64编码大小

## 🚀 性能优化方案

### 1. **批量处理**
- 单张处理避免内存爆炸
- 处理完一张后清理内存
- 使用Promise.allSettled避免单点失败

### 2. **缓存策略**
- 缓存模型加载状态
- 复用已加载的模型
- 避免频繁加载/卸载

### 3. **监控和清理**
- 实时监控内存使用
- 超过80%时触发垃圾回收
- 定期清理无用数据

## 🛠️ 故障排除

### 内存不足
1. 重启Ollama服务
2. 使用CPU模式
3. 减少图片尺寸
4. 降低上下文长度

### 响应超时
1. 增加超时时间到60秒
2. 检查模型是否正常加载
3. 使用更小的模型

### 质量不佳
1. 使用更大的模型
2. 优化提示词
3. 增加图片分辨率
4. 调整温度参数
