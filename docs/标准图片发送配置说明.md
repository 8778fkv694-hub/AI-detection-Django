# 标准图片发送配置功能说明

## 功能概述

为了优化检测效率和降低成本，系统提供了标准图片发送配置功能，允许用户选择是否在每次检测时发送标准图片给AI模型。**无论选择哪种模式，系统都会自动整合ROI区域信息到检测提示词中**。

## 两种检测模式

### 模式1：仅使用ROI区域信息（推荐）
- **特点**：不发送标准图片，仅使用ROI区域的位置和描述信息
- **ROI信息整合**：
  - 区域名称和描述
  - 相对位置信息（如"左侧上方的小区域"）
  - 检测重点指导
- **优势**：
  - 减少数据传输量
  - 降低AI处理成本
  - 提高检测速度
  - 减少网络带宽占用
- **适用场景**：
  - ROI区域描述清晰明确
  - 检测标准相对简单
  - 对成本敏感的场景

### 模式2：发送标准图片对比
- **特点**：同时发送检测图片和标准图片给AI
- **ROI信息整合**：
  - 区域名称和描述
  - 相对位置信息
  - 图片对比指导
  - 重点关注区域说明
- **优势**：
  - 提高检测精度
  - 更好的视觉对比效果
  - 适合复杂检测场景
- **适用场景**：
  - 复杂的视觉检测需求
  - ROI区域描述不够详细
  - 对精度要求极高的场景

## 配置方法

### 在标准设定中配置

1. **创建或编辑标准模板**
   - 进入"标准设定"页面
   - 上传标准图片
   - 标注ROI区域

2. **设置发送选项**
   - 在标准图片下方会出现"检测时发送标准图片"开关
   - 根据需求选择开启或关闭

3. **保存配置**
   - 点击"保存模板"
   - 配置会与模板一起保存

## 智能提示词增强

**重要：无论是否发送标准图片，系统都会自动增强提示词**

### 模式1：仅ROI信息的提示词
```
请严格按照以下标准检测：
- 标准名称: [模板名称]
- 附加标准: [检测要求]
- 重点关注区域:
  1. [区域名称]: [区域描述]
  2. [区域名称]: [区域描述]
  ...

请特别关注上述标注的区域，这些是检测的重点。

区域位置参考：
  1. [区域名称]: 位于[位置描述]
  2. [区域名称]: 位于[位置描述]
  ...

检测说明：请根据上述ROI区域的位置和描述信息，仔细检查检测图片中对应区域，判断是否符合标准要求。
```

### 模式2：发送标准图片的提示词
```
请严格按照以下标准检测：
- 标准名称: [模板名称]
- 附加标准: [检测要求]
- 重点关注区域:
  1. [区域名称]: [区域描述]
  2. [区域名称]: [区域描述]
  ...

请特别关注上述标注的区域，这些是检测的重点。

区域位置参考：
  1. [区域名称]: 位于[位置描述]
  2. [区域名称]: 位于[位置描述]
  ...

检测说明：我将提供标准图片和检测图片，请对比两张图片，重点关注上述ROI区域，检查是否存在缺陷或不符合标准的情况。
```

### 位置描述示例
- "左侧上方的小区域"
- "中央中部的中等区域"
- "右侧下方的大区域"

## 性能对比

| 配置模式 | 数据传输量 | 检测速度 | 检测精度 | 成本 | ROI信息整合 |
|---------|-----------|---------|---------|------|------------|
| 仅ROI信息 | 低 | 快 | 中等 | 低 | ✅ 完整 |
| 发送标准图 | 高 | 慢 | 高 | 高 | ✅ 完整+图片对比 |

## 最佳实践建议

### 1. 根据检测复杂度选择
- **简单检测**：使用仅ROI信息模式
- **复杂检测**：使用发送标准图片模式

### 2. ROI区域描述优化
- 提供详细、准确的区域描述
- 包含关键特征和检测要点
- 使用标准化的描述语言

### 3. 成本控制
- 对于批量检测，优先使用仅ROI信息模式
- 对于关键检测，可以使用发送标准图片模式
- 根据实际效果调整配置

### 4. 测试验证
- 创建测试用例验证两种模式的效果
- 根据检测结果选择最适合的配置
- 定期评估和调整配置

## 技术实现

### 前端配置
- 在标准设定页面提供开关选项
- 配置与模板一起保存
- 提供清晰的说明和提示

### 后端处理
- 根据配置决定是否发送标准图片
- **无论哪种模式都整合ROI信息到提示词**
- 智能位置描述自动生成
- 根据模式提供不同的检测指导

### 数据库存储
- `sendStandardImage` 字段存储配置
- 支持布尔值存储
- 向后兼容现有数据

## 注意事项

1. **ROI信息始终有效**：无论选择哪种模式，ROI区域信息都会被整合到提示词中
2. **配置影响**：配置更改会影响所有使用该模板的检测
3. **性能考虑**：发送标准图片会增加检测时间
4. **成本控制**：合理使用两种模式以控制成本
5. **测试建议**：建议在实际使用前进行充分测试

## 故障排除

### 常见问题
1. **配置不生效**：检查模板是否正确保存
2. **检测精度下降**：考虑开启标准图片发送
3. **检测速度慢**：考虑关闭标准图片发送
4. **ROI信息不显示**：检查ROI区域是否正确标注
